# SLIDE-PATTERN-attribute-table-with-summary-row

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** attribute-table-with-summary-row
**概要：** 「項目・現状値・概要説明・判断/目標」の4列テーブルを縦に並べ、最終行を全列結合の「まとめ・総括」行として配置するレポート形式テーブルレイアウト。
**適したシーン：** 業務の現状分析レポート、KPIの実績と課題の整理、複数の定量指標を項目別に説明しながら最後に総括を示したいスライド。

## Structure（構造）

コンテンツエリア上部に小見出し（テーブルの主題）を配置し、その下いっぱいにテーブルを1つ配置する単一カラムレイアウト。テーブルはヘッダー行（項目名・現状/定量・概要・判断or目標の4列）と、複数のデータ行（各行1項目、行の左端セルに項目名、次に強調色の大きな数値、続いて詳細説明文、最後に判断・目標の短いラベル）で構成される。最終行のみ4列すべてを横断結合し、背景色を変えて「まとめ・総括」として2〜3文の総括テキストを収める。行間は罫線または背景の縞模様で区切り、左端の項目名セルと最終行はアクセントカラーの背景で強調される。視線は上（小見出し）→表を上から下→最終行（総括）の順に流れる。

    structure:
      layout: single
      top_heading:
        height: 8%
        type: text
        role: テーブルの主題を示す小見出し（ダイヤ等の装飾つき）
      table:
        height: 92%
        columns: 4
        column_roles: [項目名, 現状値（定量）, 概要説明, 判断/目標]
        header_row:
          background: アクセントカラー塗り・白文字
        data_rows:
          count: 4〜5
          first_column: アクセントカラー背景・白文字（項目名）
          second_column: 大きな数値強調（アクセントカラー文字）
          third_column: 詳細説明文（2〜3行）
          fourth_column: 短い判断・目標ラベル
        summary_row:
          span: 4列結合
          background: アクセントカラー塗り・白文字
          role: 全体の総括を2〜3文で示す

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。

| 要素 | 配置 | 役割 |
|---|---|---|
| 小見出し | コンテンツエリア最上部 | テーブル全体の主題（例：◆ 月次レポート、22px相当） |
| ヘッダー行 | テーブル最上部 | 各列の名称（項目／現状（定量）／概要／判断・目標、24px相当） |
| 項目名セル | 各データ行左端 | 分析対象の項目名（アクセントカラー背景で強調、26px相当） |
| 定量値セル | 各データ行2列目 | 現状の数値（大きく・アクセントカラー文字、38px相当） |
| 概要セル | 各データ行3列目 | 数値の背景・要因を説明する文章（2〜3行、20px相当） |
| 判断/目標セル | 各データ行4列目 | その項目に対する評価や目標値（短いラベル、22px相当） |
| まとめ行 | テーブル最終行 | 全項目を総括する2〜3文のテキスト（4列結合、20px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-attribute-table-with-summary-rowのレイアウトで、[分析対象の項目群]の現状値・概要・判断を整理し、最後に総括を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- データ行数は4〜6行程度が読みやすい。項目が多い場合はフォントサイズを詰めるより行を絞ることを優先する
- まとめ行は他の行と視覚的に明確に区別できるよう、背景色や文字色を変える
- 定量値セルは他のセルより目立つフォントサイズ・太さにして視線を誘導する
