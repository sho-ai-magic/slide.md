# SLIDE-PATTERN-staircase-roadmap-with-detail-box

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** staircase-roadmap-with-detail-box
**概要：** 左下から右上へ階段状に積み上がる5段階のステップを、各段を情報量の多い横長ボックス（番号＋アイコン＋見出し＋説明＋難易度・所要時間）として表現し、右上に進行矢印、右下に補足ボックスを添えるロードマップレイアウト。
**適したシーン：** 難易度順・段階順に並んだ複数の活用事例・導入ステップを、各段の詳細情報（難易度・所要時間等の定量情報）付きで見せたいスライド。活用事例の紹介、習熟度別ガイド、段階的な導入プランの説明。

## Structure（構造）

コンテンツエリア上部にリード文を1〜2行配置し、その下いっぱいに5段階の階段状ステップを左下から右上へ積み上げて配置する。各段は横長の角丸ボックスで、左側に大きな段階番号と円形アイコン、中央に見出し（太字）と説明文（1〜2行）、右側に難易度（星アイコンの数）と所要時間（Before→After形式の短縮表現）を配置する横並び構成。段が上がるごとにボックスの縦位置が高くなり、全体として右上がりの階段を形成する。最上段の右上には全体の進行を示す大きな矢印を配置し、右下の空きスペースには「まず何から始めるか」等の補足ガイドボックス（アイコン＋見出し＋本文）を配置する。視線は左下（最も簡単な段階）→右上（最も難易度の高い段階）へと階段を上るように流れる。

    structure:
      layout: staircase
      top_lead:
        height: 10%
        type: text
        role: 全体の主旨を示すリード文（1〜2行）
      staircase:
        height: 90%
        container: position:relative の領域として扱い、各段・矢印・補足ボックスをその中に絶対配置する
        steps:
          count: 5
          direction: 左下から右上へ階段状
          step_structure: 段階番号（大） → 円形アイコン → 見出し（太字） → 説明文（1〜2行） → 難易度（星） → 所要時間（Before→After）
          shape: 横長の角丸ボックス
          box_width: コンテナ幅の58%で固定（右下の補足ボックスと重ならないよう、幅は変えずに補足ボックス側で調整する）
          box_height: コンテナ高さの15%
          left_offset_step: 段が1つ上がるごとに左位置をコンテナ幅の8%ずつ右へずらす（1段目0%→5段目32%）
          bottom_offset_step: 段が1つ上がるごとに下端位置をコンテナ高さの18%ずつ上へずらす（1段目0%→5段目72%）。5段目の上端（72%+15%=87%）がコンテナの100%を超えないようにし、上部にリード文・進行矢印との余白を確保する
        progress_arrow:
          position: コンテナ右上（top:0; right:0）
          role: 全体の進行方向を示す大きな矢印
        supplementary_box:
          position: コンテナ右下（right:0; bottom:0）
          width: コンテナ幅の30%程度（ステップボックスの右端、特に2段目の右端＝left8%+box_width58%=66%と重ならないよう、幅はステップ側ではなく補足ボックス側で調整する）
          height: コンテナ高さの32%程度
          role: 「まず何から始めるか」等の補足ガイド（アイコン＋見出し＋本文）

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| リード文 | コンテンツエリア最上部 | 全体の主旨を示す説明文（1〜2行、20px相当） |
| 段階番号 | 各段左端 | ステップの順序を示す大きな数字（48px相当） |
| 円形アイコン | 段階番号の隣 | その段階の内容を象徴するアイコン。生成時に内容に沿ったSVGアイコンを生成する |
| 見出し | 各段中央 | ステップの名称（26px相当） |
| 説明文 | 見出しの下 | ステップの内容説明（1〜2行、18px相当） |
| 難易度 | 各段右側 | 星アイコンの数で難易度を示す（18px相当） |
| 所要時間 | 難易度の下 | 短縮効果を示すBefore→After表現（22px相当） |
| 進行矢印 | 最上段の右上 | 階段全体の進行方向・上昇イメージを示す |
| 補足ガイドボックス | 右下の空きスペース | 最初に着手すべき内容を案内する補足情報（本文18px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-staircase-roadmap-with-detail-boxのレイアウトで、[5段階の活用事例・ステップ]と、[各段の難易度・所要時間]、[補足ガイドの内容]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- ステップ数は5を基本とするが、3〜6段階程度まで調整可能。段数が変わっても階段の傾斜角度は一定に保つ
- 既存の`staircase-roadmap-with-icons`（丸バッジ中心のシンプルな階段ロードマップ）と近い構造だが、本パターンは各段が横長ボックスで難易度・所要時間の定量情報を持つ点、右下に独立した補足ガイドボックスを持つ点が差分となる
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
- 階段の各段は縦位置の積み上げ幅（bottom_offset）に対して段の高さ（box_height）を必ず小さく設計し、最上段の上端がコンテナの100%を超えないようにする。超えるとコンテンツエリア外にはみ出し、リード文や進行矢印と重なって見える
- ステップボックスと右下の補足ガイドボックスが重なる場合は、ステップボックスの幅を縮めるのではなく、補足ガイドボックスの幅・配置を調整して重なりを回避する（ステップボックスの横幅は情報量が多く縮めると窮屈になるため）
