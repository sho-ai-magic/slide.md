# SLIDE-PATTERN-board-member-photo-row-with-matrix

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** board-member-photo-row-with-matrix
**概要：** 上部に複数人の顔写真・氏名・役職を横一列に並べ、その下に担当領域（行）×人物（列）のドット形式マトリクス表を配置し、最終行に各人物の経歴文を長文セルとして収めるレイアウト。
**適したシーン：** 取締役会・経営会議メンバー等、多人数（7〜10名程度）の担当領域と経歴を1枚で一覧化したいスライド。IR資料のガバナンス体制説明、取締役紹介ページ。

## Structure（構造）

コンテンツエリア上部に、人数分の顔写真プレースホルダー・氏名・役職を横一列に等間隔で配置する（写真は円形または正方形、氏名太字・役職は氏名の下に小さく表示）。その下いっぱいに、左端に担当領域ラベル列（経営・ファイナンス・ガバナンス等の行見出し）を持つマトリクス表を配置し、各列は上部の人物に対応する。表の本体行は該当する担当領域にドットマーカーを配置する形式で、最終行のみ人物ごとの経歴文（学歴・職歴を箇条書きで4〜6項目）を収める長いセルになる。人数が多いため列幅は狭く均等割りとし、視線は上（顔写真の一覧）→下（担当領域と経歴のマトリクス）に流れる。

    structure:
      layout: top-bottom-split
      photo_row:
        height: 22%
        columns: N（人数分、7〜10列程度）
        item_structure: 顔写真プレースホルダー（円形/正方形） → 氏名（太字） → 役職（小）
      matrix_table:
        height: 78%
        columns: N+1（左端の担当領域ラベル列 + 人物分の列）
        rows: 担当領域の行数（5〜6行） + 経歴行（最終行、長文セル）
        cell_type: ドットマーカー（担当領域に該当する場合のみ表示）
        last_row: 経歴文（学歴・職歴を箇条書き4〜6項目、セル内は小さめフォント）

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」として扱う。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| 写真添付エリア | 各列最上部 | 人物の顔写真。後から実際の写真に差し替える |
| 氏名 | 写真の下 | 人物名（太字、16px相当） |
| 役職 | 氏名の下 | 役職名（12px相当） |
| 担当領域ラベル列 | マトリクス表左端 | 各行が示す担当領域の名称（14px相当） |
| ドットマーカー | 各セル | その人物がその担当領域を持つことを示す印 |
| 経歴セル | 最終行 | 学歴・職歴を箇条書きで示す長文（10px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-board-member-photo-row-with-matrixのレイアウトで、[人物の氏名・役職]と、[各人物の担当領域]、[経歴]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 人数が多いレイアウトのため、列幅が狭くなる分フォントサイズは他パターンより小さめになるが、氏名・担当領域ラベルなど主要情報は視認性を優先して極端に縮小しない
- 経歴セルの箇条書きは1人あたり4〜6項目程度に絞り、文字が小さくなりすぎないようにする
- 人数が5名以下の場合は、列幅を広げて写真を大きくしてもよい
