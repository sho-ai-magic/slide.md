# SLIDE-PATTERN-donut-chart-4up-with-box

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** donut-chart-4up-with-box
**概要：** 見出し・リード文の下に、白背景のボックスで囲んだエリア内に4つのドーナツチャート（ラベル・上向き矢印アイコン・中央パーセント数値・キャプション）を等間隔で横並びに配置するレイアウト。
**適したシーン：** アンケート調査結果や導入効果測定など、4つの評価項目それぞれの達成率・満足度をまとめて提示したいスライド。調査結果のサマリー、導入効果レポート。

## Structure（構造）

コンテンツエリア上部に見出し（1行）とリード文（1行、アクセントカラーで強調）を配置し、その下に補足の小見出しを1行添える。その下いっぱいに、薄いグレーの背景・角丸のボックスを1つ配置し、ボックス内を4等分して4つのドーナツチャートを横並びに配置する。各ドーナツチャート項目は、上部にラベル文言と上向き矢印アイコン（改善・向上を示す）、中央にドーナツグラフ本体（円環の一部を進捗として塗り分け、中心に大きなパーセント数値）、下部にキャプション（1〜2行の補足説明）を縦に配置する。4項目は同じ内部構成を繰り返し、視線は上（見出し・リード文）→ボックス内を左から右へ4項目を順に読む横方向の流れとなる。

    structure:
      layout: top-bottom-split
      top_heading:
        height: 12%
        type: text
        role: 見出し（1行）とリード文（1行、アクセントカラー強調）、補足小見出し（1行）
      box:
        height: 70%
        shape: 薄いグレー背景・角丸のカードボックス
        columns: 4
        gap: 均等割り
        item_structure: ラベル＋上向き矢印アイコン（上部） → ドーナツグラフ本体＋中央パーセント数値（中央） → キャプション（下部、1〜2行）

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-donut-chart-4up-with-boxのレイアウトで、[4つの評価項目名]と、[各項目の達成率・キャプション]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 4項目の達成率は視覚的に比較しやすいよう、ドーナツの塗り分け角度を実際の数値に比例させる
- 項目数が3つ以下の場合はボックス内の等分数を減らして幅を広げる
- 上向き矢印アイコンは数値が向上・改善している場合のみ使用し、低下している項目には別の表現（下向き矢印・注意アイコン等）に差し替える
