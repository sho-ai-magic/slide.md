# SLIDE-PATTERN-section-divider-diagonal-geometric

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** section-divider-diagonal-geometric
**概要：** 背景全面に対角線の幾何学的なストライプ模様を敷き、右上にロゴ、コンテンツエリア中央よりやや右下にセクション番号・タイトル・サブタイトルを配置する章区切りレイアウト。
**適したシーン：** プレゼン資料の章・セクションの切り替え。シャープでスタイリッシュな印象を与えたい章区切りページ、テクノロジー・金融系資料のセクション導入。

## Structure（構造）

本パターンは表紙・章区切り専用のデザインとして、スライド全体（タイトルエリア・フッターエリアを含む）を使う。SLIDE.mdの通常の`Slide Frame`は表示せず、背景装飾・ロゴ・テキストのみでスライド全面を構成する。スライド全面に、左上から右下へ向かう対角線の帯（濃淡の異なる幾何学的なストライプ）を背景装飾として敷く。右上にロゴを配置し、テキストブロックは他の章区切りパターンと異なり画面中央よりやや右下寄りに配置する。テキストブロックは「Section 数字」の英語ラベル、番号付きの和文タイトル、英語サブタイトルを縦に並べる構成で、左揃えを保つ。装飾の対角線は左上部に集中し、右下のテキストエリア周辺は余白を確保して可読性を保つ。視線は右上（ロゴ）→中央右下（セクション情報）の順に流れる。

    structure:
      layout: single
      frame_note: SLIDE.mdの通常のSlide Frame（タイトル帯・ブランドフッター・ページ番号）は使わない。表紙・章区切り専用のフルスライドデザインとして扱う
      background:
        type: 対角線の幾何学的ストライプ模様（左上に集中、右下は余白）
        role: コンテンツエリア全体を覆う装飾
      logo:
        position: 右上
        role: ブランドロゴ
      text_block:
        position: 中央よりやや右下寄り、左揃え
        item_structure: セクションラベル（英語、小） → 番号付き和文タイトル（大） → 英語サブタイトル（小）

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| 背景幾何学模様 | コンテンツエリア左上に集中 | シャープな印象を与える対角線の装飾 |
| ロゴ | 右上 | ブランドを示す小さなロゴマーク（20px相当） |

| セクションタイトル | セクションラベルの下 | 番号付きの章タイトル（例：01 会社概要、36px相当） |
| サブタイトル | セクションタイトルの下 | 英語の補足タイトル（16px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-section-divider-diagonal-geometricのレイアウトで、[セクション番号・タイトル・サブタイトル]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 本パターンは表紙・章区切り専用デザインのため、SLIDE.mdの通常のタイトルエリア・フッターエリア（ブランドフッター・ページ番号）は使わない。スライド全面を使って独自にレイアウトする
- ロゴ位置（右上）とテキスト位置（中央よりやや右下）が、他の章区切りパターン（`section-divider-image-right-tech`等の左上ロゴ・左下テキスト）と異なる点に注意する
- 対角線の装飾はテキストエリアと重ならないよう、左上側に寄せて配置する
