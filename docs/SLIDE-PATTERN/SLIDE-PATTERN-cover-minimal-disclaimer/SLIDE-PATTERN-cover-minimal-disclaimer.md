# SLIDE-PATTERN: cover-minimal-disclaimer

このファイルはスライド全面を使うレイアウトパターン定義書です。タイトルエリア・フッターは使用しません。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** cover-minimal-disclaimer
**概要：** 白背景ミニマルデザイン。左上にロゴ、中央にタイトル・発表者情報、最下部に免責事項テキスト行を持つ表紙レイアウト。金融・法務資料に適した。
**適したシーン：** 金融商品説明、投資戦略プレゼン、規制対象の商品説明、免責事項が必須の業界資料

## Structure（構造）

```
structure:
  frame: none
  layout: single-column
  sections:
    header: [logo-left, company-name]
    body: [main-title, presenter-name, date-event]
    footer: [disclaimer-text]
```

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真・ロゴは「写真添付エリア（後から実際の写真に差し替え）」として扱う。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| ロゴ＋会社名 | 左上 | ブランドアイデンティティ（ロゴは写真添付エリア、会社名26px相当） |
| メインタイトル | 中央 | 資料・発表のタイトル（60px相当） |
| 発表者名 | タイトル下 | 著者・登壇者情報（28px相当） |
| 日付・イベント名 | 発表者下 | 発表コンテキスト（26px相当） |
| 免責事項 | 最下部 | 法的免責・金融商品取引業登録情報等（20px相当） |

## Usage Guide（AIへの使い方）

- 免責事項テキストは金融・証券会社向け資料に必須。2〜3行まで対応
- ロゴエリアの横にサービス名ラインを追加可能。ロゴは「写真添付エリア」としてプレースホルダーのまま生成し、ユーザーが後から実際のロゴに差し替える
- タイトル下の余白は発表者情報が多い場合に調整可能
- 免責事項フォントサイズは18〜20px相当が適切。それ以下は可読性が著しく低下する
- ヘッダー・ボディ・フッターの3セクション構成を崩さないことで情報の階層が明確になる
- 金融規制上必要な登録番号・協会名は省略不可。文字数が多い場合は2行に分割する
