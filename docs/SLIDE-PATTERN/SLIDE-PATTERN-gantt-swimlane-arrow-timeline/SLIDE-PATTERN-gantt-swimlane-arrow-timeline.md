## Overview

**パターン名：** gantt-swimlane-arrow-timeline
**概要：** 左側にカテゴリ帯（ラベル＋詳細説明）を縦に並べたスイムレーンを配置し、右側に月区切りの矢印付き時間軸と、各カテゴリ行に開始位置・長さが可変な矢印バー（期間＋内容ラベル付き）を重ねて配置するガントチャート風タイムラインレイアウト。
**適したシーン：** 複数のタスク・工程が並行して進む期間を、月単位の時間軸上で視覚的に比較しながら示したいスライド。プロジェクトのスケジュール説明、複数施策の実施期間の可視化。

## Structure（構造）

コンテンツエリア上部にリード文を2行配置し、その下いっぱいに左右2カラムのスイムレーン表を配置する。左カラム（約32%）はカテゴリ帯を縦に2〜3段積み、各帯は左側にカテゴリ名（濃色背景・中央揃え）、右側に詳細説明文（グレー背景）を横並びに配置する。右カラム（約68%）の最上部には月区切りの時間軸を配置し、各月の間を両端矢印の区切り線と縦の点線で示す。時間軸の下、各カテゴリ帯に対応する高さに、開始位置・長さが可変な矢印バー（内部に期間ラベルと内容説明を白抜きで表示）を配置する。矢印バーの色の濃さや太さで重要度・段階を区別してもよい。カテゴリ帯の境界には全体を貫く横罫線を1本引く。視線は左（カテゴリ）→右（時間軸に沿った矢印バーの位置・長さ）の順に流れる。

    structure:
      layout: two-column
      top_lead:
        height: 10%
        type: text
        role: 背景・目的を示すリード文（2行）
      left:
        width: 32%
        type: category-swimlane
        role: カテゴリ帯（縦積み）
        rows:
          count: 2〜3
          item_structure: カテゴリ名（濃色背景・中央揃え） + 詳細説明文（グレー背景・左揃え）の横並び
      right:
        width: 68%
        type: gantt-timeline
        role: 月区切りの時間軸と矢印バー
        month_axis:
          position: 最上部
          shape: 両端矢印付きの区切り線＋縦の点線
        arrow_bars:
          count: カテゴリ行数と同数以上（1行に複数本配置可）
          shape: 太い矢印バー（開始位置・長さ可変）
          content: 期間ラベル＋内容説明（白抜き文字）
      row_divider: 横罫線でカテゴリ行を区切る

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |

| カテゴリ名 | 左カラム各行左側 | 工程・タスクの分類名（濃色背景、26px相当） |

| 月区切り軸 | 右カラム最上部 | 時間軸の月単位の目盛り（24px相当） |
| 矢印バー | 各カテゴリ行の時間軸上 | 期間の開始・終了・内容を示す視覚要素（内部テキスト20px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-gantt-swimlane-arrow-timelineのレイアウトで、[カテゴリ名・詳細データ]と、[各カテゴリの期間・内容を示す矢印バー]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- カテゴリ行数は2〜4行程度まで調整可能。行数が増える場合は行の高さを詰めて対応する
- 矢印バーは複数本を1行に配置してもよく、時系列で前後の工程が連続する場合は矢印同士を隣接させて流れを示す
- 月区切りの時間軸の月数は、実際のスケジュール期間に応じて3〜6ヶ月程度で調整する
