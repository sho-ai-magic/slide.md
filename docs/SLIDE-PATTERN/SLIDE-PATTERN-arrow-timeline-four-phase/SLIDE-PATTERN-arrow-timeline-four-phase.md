# SLIDE-PATTERN-arrow-timeline-four-phase

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** arrow-timeline-four-phase
**概要：** リード文の下に、太い矢印そのものをタイムラインの軸として通し、矢印上に4つの円形マーカーを配置。各マーカーから上に縦線で期間ラベルを接続し、下にフェーズ見出しと本文説明を配置するレイアウト。
**適したシーン：** 1年間・1プロジェクト等を複数フェーズに分けた時系列の全体像を、期間・フェーズ名・詳細説明とともに1枚で見せたいスライド。年間計画、事業ロードマップ、プロジェクトの段階別戦略。

## Structure（構造）

コンテンツエリア上部にリード文（見出し的な短い文＋説明文2〜3行）を配置し、その下いっぱいに水平の矢印タイムラインを配置する単一カラムレイアウト。矢印は太い帯状の右向き矢印で、スライド幅いっぱいに伸び、左右の両端に小さな開閉ナビゲーションアイコン（前後のスライドを示唆する山型矢印）を添える。矢印の上には4つの円形マーカーを等間隔に配置し、各マーカーの真上に縦線を伸ばして期間ラベル（例：1月〜3月、太字・アクセントカラー）を接続する。各マーカーの真下にはフェーズ見出し（太字・アクセントカラー）と、その下に本文説明（3〜4行）を配置する。4つのフェーズは左から右へ時系列順に並び、視線は上（リード文）→矢印上部の期間ラベル→マーカー→下部の見出しと説明の順に流れる。期間ラベル・縦線・矢印上のマーカー・フェーズ見出し/本文の4段はすべて同一の4分割グリッド（列幅・左右オフセット）を共有し、縦に一直線で繋がって見えるように配置する。

    structure:
      layout: single
      top_lead:
        height: 15%
        type: text
        role: リード文（見出し的な短文＋説明2〜3行）
        margin_bottom: 高さの約4.5%（コンテンツ全体を上下にバランスよく配分するため、タイムライン行との間に十分な余白を取る）
      timeline:
        height: 85%
        type: arrow-axis
        alignment_note: 期間ラベル行・縦線行・矢印+マーカー行・フェーズ内容行の4行すべてで、左右の外側オフセット（ナビゲーションアイコン分の幅）と内側の4分割グリッドを完全に一致させる。ズレるとマーカーと縦線・見出しの位置が揃わなくなる。
        axis_shape:
          type: 太い右向き矢印（幅いっぱい・左右の余白を除く）
          body_thickness_ratio: 矢印全体の高さに対して胴体（帯状の部分）は約65〜70%の太さ
          head_thickness_ratio: 矢じり（先端の三角形）は胴体の約1.5倍の太さ（矢印全体の高さいっぱいまで広がる）。矢じりの根本・先端の座標は要素の0〜100%の範囲に収め、範囲外にはみ出す値を指定しない（クリップされて形が崩れるため）
          head_length_ratio: 矢じりの横方向の長さは矢印全体の幅の約10%
        markers:
          count: 4
          shape: 円形マーカー・矢印の胴体太さに収まるサイズで矢印上に等間隔配置
          period_label:
            position: 各マーカーの真上、縦線で接続
            role: 期間・フェーズの時期を示すラベル
          phase_body:
            position: 各マーカーの真下
            item_structure: フェーズ見出し（太字） → 本文説明（3〜4行）
            vertical_align: フェーズ内容の行はコンテンツエリアの残り高さを埋めるように伸縮させ、上下中央寄せにして下部だけが不自然に空かないようにする

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| リード文見出し | コンテンツエリア最上部 | フェーズ構成全体の主題（例：年間戦略（4フェーズ構成）、22px相当） |
| リード文本文 | 見出しの下 | 全体の流れ・目的を示す説明文（2〜3行、18px相当） |
| 矢印タイムライン軸 | コンテンツエリア中央を横断 | 4フェーズが時系列で進行することを示す帯状の矢印 |
| 開閉ナビゲーションアイコン | 矢印の左右両端 | 前後のスライド・フェーズへの遷移を示唆する山型矢印 |
| 期間ラベル | 各マーカー上部（縦線接続） | そのフェーズの実施時期（例：1月〜3月、22px相当） |
| 円形マーカー | 矢印上に等間隔配置 | フェーズの区切り位置を示す視覚的な点 |
| フェーズ見出し | 各マーカー下部 | フェーズの名称（20〜24px相当） |
| フェーズ本文 | フェーズ見出しの下 | フェーズの取り組み内容の説明（3〜4行、16px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-arrow-timeline-four-phaseのレイアウトで、[全体の目的]と、[4つのフェーズの期間・名称・取り組み内容]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- フェーズ数は4を基本とするが、3〜5フェーズ程度まで調整可能。増減時は矢印上のマーカー間隔を均等に保つ
- 各フェーズの期間の長さが実際は不均等でも、矢印上のマーカー間隔は視認性を優先して均等配置してよい
- 既存の`horizontal-timeline-cards`（点線＋ドットマーカー＋下にステップカード）と近い構造だが、本パターンは矢印そのものが軸になっている点、期間ラベルを縦線でマーカー上部に接続する点が差分となる
- 矢印は「胴体が細い帯・矢じりが胴体より太い三角形」になるよう形状比率（胴体約65〜70%、矢じり約100%の太さ）を守る。矢じりを鋭角にしすぎる（胴体からいきなり尖る）と鉛筆のような見た目になるため避ける
- 期間ラベル・縦線・矢印上のマーカー・フェーズ見出し/本文の4段は、同じ左右オフセットと4分割グリッドを共有させて縦に一直線に揃える。行ごとに異なる余白・パディングを設定すると位置がズレる
- コンテンツ全体が上に寄って下部だけが空かないよう、フェーズ内容の行を残り高さに合わせて伸縮させ、上下中央寄せにする
