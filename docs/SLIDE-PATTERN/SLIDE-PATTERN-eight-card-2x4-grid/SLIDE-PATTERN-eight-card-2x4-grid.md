## Overview

**パターン名：** eight-card-2x4-grid
**概要：** コンテンツエリアに2行×4列の計8カードをグリッド配置し、各カードに番号バッジ・見出し・説明テキストを収める大容量情報カードレイアウト。
**適したシーン：** 施策一覧、機能紹介、取り組み概要、チェックリストなど、多数の施策・機能・特長・手順を1スライドでコンパクトに一覧表示したい場合。情報密度は高（8項目×各3要素の同時表示）で、網羅感・一覧性を重視する場面に適する。

## Structure（構造）

コンテンツエリア全体を2行×4列のグリッドで埋め、各セルに番号バッジ・見出し・説明テキストを持つカードを配置する。カードは均等サイズで、視線は左上から右方向、上段→下段の順に流れる。

    structure:
      frame: standard
      layout: grid-2x4-cards
      grid:
        columns: repeat(4, 1fr)
        rows: repeat(2, 1fr)
        gap: 20px（高さの約2%）
        count: 8
      card:
        border: 1px solid #E0E0E0
        padding: 24px
        layout: flex-column
        gap: 12px
        elements:
          - number-badge (width:48px / height:48px / border-radius:50%)
          - heading (font-size:26px)
          - description (font-size:22px / 2行)

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-eight-card-2x4-gridのレイアウトで、[8つの施策/機能/ステップ]をそれぞれ見出しと説明文で配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 8カードは「施策1〜8」「機能A〜H」「ステップ01〜08」のように統一した命名で揃える
- 見出しは10文字以内、説明テキストは30〜40文字（2行）を目安にすると収まりが良い
- 番号バッジの背景色をカテゴリごとに変えることで、グループ分けを視覚化できる
- カードの行高さが揃うよう、説明テキストの文字数を各カードで均等に調整する
- 8カードすべてに内容を記述することが前提。空カードが生じる場合は別パターンを選ぶ
