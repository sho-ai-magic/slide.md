# SLIDE-PATTERN-phase-banner-four-column-icon-checklist

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** phase-banner-four-column-icon-checklist
**概要：** リード文の下に全幅のフェーズ見出し帯を配置し、その下を4列に分割して、各列に「番号バッジ＋見出し」「中央の大きなアイコン」「中央寄せの本文」「取り組みチェックリスト」を縦積みするレイアウト。
**適したシーン：** 特定フェーズで並行して進める4つの施策・取り組みを、内容を象徴するアイコンとともに説明したいスライド。DX推進計画の中期フェーズ詳細、複数施策の並列提示。

## Structure（構造）

コンテンツエリア上部にリード文を2行配置し、その下に全幅のフェーズ見出し帯（濃色背景・白文字・中央揃えでフェーズ名と期間を示す）を配置する。帯の下は4列均等に分割され、列間に区切り線や背景の変化はなく、余白のみで区切る。各列は「丸い番号バッジ＋見出し（横並び、列上部）」から始まり、その下に中央揃えで大きめのアイコンを配置し、続いて中央揃えの本文（1〜2行、施策の要点）、最後に「主な取り組み」等の小見出しとチェックマーク付きの箇条書き項目（3項目程度、左揃え）が続く。4列は同じ内部構成を繰り返し、視線は上（フェーズ帯）→左から右へ4列を順に読む横方向の流れとなる。

    structure:
      layout: top-bottom-split
      top_lead:
        height: 10%
        type: text
        role: フェーズ全体の主旨を示すリード文（2行程度）
      phase_banner:
        height: 6%
        type: text
        role: フェーズ名・対象期間を示す全幅の帯（濃色背景・白文字・中央揃え）
      column_row:
        height: 78%
        columns: 4
        divider: なし（余白のみで区切る）
        item_structure: 番号バッジ＋見出し（横並び・列上部） → 大きめアイコン（中央揃え） → 本文1〜2行（中央揃え） → 小見出し → チェックマーク付き箇条書き3項目（左揃え）

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| リード文 | コンテンツエリア最上部 | フェーズ全体の主旨を示す説明文（2行、22px相当） |
| フェーズ見出し帯 | リード文の下 | フェーズ名・対象期間を示す全幅バナー（26px相当） |
| 番号バッジ | 各列上部 | 列の順序を示す丸バッジ（20px相当） |
| 列見出し | 各列上部・番号バッジの右 | その列の施策名（22px相当） |
| アイコン | 各列中央 | 施策の内容を象徴する大きめのアイコン。生成時に内容に沿ったSVGアイコンを生成する |
| 本文 | アイコンの下 | 施策の要点（中央揃え、1〜2行、20px相当） |
| 小見出し | 本文の下 | 取り組み一覧の見出し（例：主な取り組み、20px相当） |
| チェックマーク付き箇条書き | 各列最下部 | 具体的なアクション項目（3項目、左揃え、18px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-phase-banner-four-column-icon-checklistのレイアウトで、[フェーズ名・期間]と、[4つの施策の見出し・アイコンの内容・取り組み項目]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 4列は同じ内部構成を維持し、アイコンの視覚的な重みを揃えると統一感が出る
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
- 既存の`phase-banner-three-column-metric-checklist`（3列・数値ハイライトボックスあり・縦罫線区切り）と近い系統だが、本パターンは4列でアイコンを主役に据え、数値ハイライトボックスと列区切り線を持たない点が差分となる
