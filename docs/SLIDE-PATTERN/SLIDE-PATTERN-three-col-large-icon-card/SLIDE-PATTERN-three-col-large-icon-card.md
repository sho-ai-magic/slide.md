# SLIDE-PATTERN-three-col-large-icon-card

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** three-col-large-icon-card
**概要：** 3列均等に並んだカードレイアウト。各カードは上部にアイコン＋見出しのヘッダーゾーン（アクセントカラー背景）と、下部に箇条書きリストのボディゾーンで構成される2段構造。
**適したシーン：** 3つの特徴・理由・強みを並列で比較・紹介するスライド。各項目に複数の根拠や詳細を箇条書きで添えたいとき。

## Structure（構造）

コンテンツエリアを3等分した列にカードを配置する。各カードは垂直方向に「ヘッダーゾーン（アイコン＋見出し）」と「ボディゾーン（箇条書きリスト）」の2つのセクションに分かれる。ヘッダーは塗り背景で強調し、アイコンはカード左上隅の折り返し装飾（ドッグイヤー）として表現することもある。上部にはオプションでサブタイトル行（1行のリード文）を配置できる。

    structure:
      frame: standard
      layout: three-column-grid
      lead_text_optional: true   # コンテンツエリア最上部にオプションで1行のリード文
      column_count: 3
      card_structure:
        header:
          elements: [icon, heading]
          background: accent-color
        body:
          elements: [bullet-list]
          item_count: 3
      gap: equal

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」、アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| リード文（任意） | コンテンツエリア最上部 | カード群を補足する1行のテキスト（22px相当） |
| カードヘッダー | 各カード上部 | アクセントカラー背景でカードのテーマを視覚的に区別 |
| アイコン | ヘッダー左（またはドッグイヤー） | カードテーマを象徴するアイコンまたは折り返し装飾。内容に沿ったSVGアイコンを生成して配置 |
| 見出し | ヘッダー右（または中央） | カードのタイトル（2〜4語の短い見出し、26px相当） |
| 箇条書きリスト | カードボディ | 各項目の詳細・根拠・特徴を3〜4つの箇条書きで記述（20px相当） |
| カード背景 | カード全体 | 薄い塗り背景でカードの領域を明示（白または薄いアクセント色） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-three-col-large-icon-cardのレイアウトで、[テーマ]の3つの[特徴/理由/強み]をカード形式で並べてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 3列の各カードの高さは揃えること（flex-stretchまたはmin-height指定）
- 各カードの箇条書き項目数は同じ数にすると整然としてバランスが良い
- ヘッダーの見出しは最大2行以内に収める
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
- コンテンツエリアとカード群の間にサブタイトル行（1行のリード文）を入れることもある
