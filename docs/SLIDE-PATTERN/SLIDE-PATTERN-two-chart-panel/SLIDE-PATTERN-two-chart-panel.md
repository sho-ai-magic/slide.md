## Overview

**パターン名：** two-chart-panel
**概要：** コンテンツエリアを左右2つのグラフパネルに分割し、各パネルにタイトルバンド・グラフ本体・凡例を配置するデータ比較レイアウト。2種類のグラフデータを対比・並置して見せる場合に適している。
**適したシーン：** 期間比較、カテゴリ別分析、A/B比較、部門別レポート。情報密度は中〜高（パネル単位で完結した情報を2セット提供）で、2つの独立データを並列比較する構成。

## Structure（構造）

コンテンツエリアを左右2つのグラフパネル（各flex:1）に分割する。各パネルは上部にパネルタイトルのヘッダーバンドを持ち、その下にグラフ本体を配置する。左パネルはドーナツグラフ1点と縦並びの凡例リストを横に組み合わせ、右パネルはドーナツグラフ2点を横並びに配置する。左右パネルの間には一定のgapを設け、パネルごとの独立性を視覚的に示す。

    structure:
      frame: standard
      layout: two-column
      gap: 40px（コンテンツエリア幅の約2%）
      left_panel:
        width: 50%（flex:1）
        header: パネルタイトルバンド
        body:
          - donut-chart（1点）
          - legend-list（縦並び）
      right_panel:
        width: 50%（flex:1）
        header: パネルタイトルバンド
        body:
          - donut-chart-pair（2点横並び）

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-two-chart-panelのレイアウトで、[製品カテゴリ構成比]（左パネル）と、[地域別シェアの今期・前期比較]（右パネル）をドーナツグラフで示すスライドを作成してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 左右パネルは独立したトピックでもよいが、同じ軸（例：今期vs前期）で対比させると説得力が増す
- 左パネルのドーナツは4〜5分割、右パネルのドーナツは2〜3分割程度が見やすい
- パネルヘッダーのタイトルは10文字以内に収めると見栄えが良い
- 凡例リストは4〜5項目が上限。それ以上はグラフ側でグルーピングを検討する
- パネル間のgapは40px（1920px基準）を維持することでパネル独立性を視覚的に示す
