このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** region-data-table-with-trend-icon
**概要：** リード文の下に、区分別の年度比較データ・構成比・前年比（上向き矢印アイコン付き）・要因説明の長文列を持つテーブルを配置し、最終行を合計として強調するレイアウト。
**適したシーン：** 地域別・部門別・カテゴリ別など複数区分の実績を年度比較しながら、伸び率と背景要因を1枚で説明したいスライド。営業実績報告・地域別売上分析・部門別KPIレポート。

## Structure（構造）

コンテンツエリア上部にリード文を1〜2行配置し、その下いっぱいにテーブルを1つ配置する単一カラムレイアウト。テーブルは太いカラーバー状のタイトル帯（テーブル全体の主題、例：「地域別 実績（今年度）」）を最上部に持ち、その下にヘッダー行（区分名／年度A数値／年度B数値／構成比／前年比／要因説明の6列）、複数のデータ行（各区分1行）、最終行に合計行（背景を強調色にして太字で表示、要因説明列のみハイフンで空欄）が続く。前年比セルには数値の右に小さな上向き矢印アイコンを添える。要因説明列は他の列より幅広く、箇条書き2行程度の文章を収める。区分名は行の左端に配置され、視線は左（区分名）→中央（数値の年度比較）→右（要因説明）の順に流れる。

## Elements（各要素の役割）

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-region-data-table-with-trend-iconのレイアウトで、[比較する区分群]の年度比較データと、[各区分の要因説明]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 区分数は4〜6行程度が読みやすい。増える場合は行の余白を詰めて対応し、フォントサイズは最低目安を下回らせない
- 前年比が減少している区分がある場合は、矢印アイコンの向きを下向きに変えて増減を視覚的に区別する
- 要因説明列は簡潔な箇条書きにとどめ、長文にしすぎない（1項目1行程度×2項目まで）
