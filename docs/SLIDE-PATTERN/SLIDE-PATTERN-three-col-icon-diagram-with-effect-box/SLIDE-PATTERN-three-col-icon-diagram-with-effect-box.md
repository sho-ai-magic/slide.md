## Overview

**パターン名：** three-col-icon-diagram-with-effect-box
**概要：** 3列均等カードで、番号バッジ＋見出し＋下線の下に内容を象徴する関係性アイコン図解（矢印付き）、本文、下部に効果・成果を示すハイライトボックス（チェックリスト）を縦積みするレイアウト。
**適したシーン：** 課題解決の3つの方向性・施策を提示し、それぞれの取り組み内容と期待される効果をセットで説明したいスライド。解決策提案、施策一覧、改善プランの提示。

## Structure（構造）

コンテンツエリア上部にリード文を1行配置し、その下を3列均等のカラムに分割する（カード枠・背景はなく、列の区切りは余白のみ）。各列は「番号バッジ（丸型）＋見出し」を横並びで配置し、見出しの下に細い下線を引く。その下に、その施策の内容を象徴する簡易的な関係性図解（複数アイコンを矢印・線でつないだミニダイアグラム）を配置し、続いて本文説明（2行程度）を置く。各列の最下部には薄い背景色のハイライトボックスを配置し、「期待される効果」等の小見出しとチェックマーク付きの効果項目（2〜3項目）を収める。3列は同じ内部構成を繰り返し、視線は上（リード文）→左から右へ3列を順に読む横方向の流れとなる。

    structure:
      layout: single
      top_lead:
        height: 8%
        type: text
        role: 3つの方向性・施策全体の主旨を示すリード文（1行）
      column_row:
        height: 92%
        columns: 3
        gap: 48px（幅の約2.5%）
        item_structure: 番号バッジ＋見出し（横並び） → 下線 → 関係性アイコン図解（矢印付きミニダイアグラム） → 本文2行 → 効果ハイライトボックス（小見出し＋チェックリスト2〜3項目）

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-three-col-icon-diagram-with-effect-boxのレイアウトで、[3つの施策の見出し・内容]と、[各施策の期待される効果]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 関係性アイコン図解は施策の内容に応じて構成を変えてよい（例：集約型は複数アイコン→中央アイコンへの矢印、連続型はアイコンを矢印でつなぐ横並び等）
- 効果ハイライトボックスの項目数は2〜3項目に絞り、簡潔に保つ
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
- 既存の`phase-banner-three-column-metric-checklist`（フェーズ帯＋数値ハイライトボックス）と近い構造だが、本パターンはフェーズ帯を持たず、下部ボックスが数値ではなくチェックリスト形式の効果一覧である点が差分となる
