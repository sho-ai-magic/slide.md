## Overview

**パターン名：** quadrant-matrix-with-ranking
**概要：** 上部にリード文、下部を左右2カラムに分割し、左に十字軸の4象限マトリクス図、右にランキングリストを配置するレイアウト。
**適したシーン：** 競合ポジショニング分析、市場マッピング、2軸で分類した要素と、それに関連する順位・比率データを同時に見せたいスライド。

## Structure（構造）

コンテンツエリアは上下2段に分かれ、上段にリード文（2行程度）、下段に左右2カラムのメインコンテンツを配置する。下段は左（約68%）に十字軸で4分割した象限マトリクス、右（約32%）にランキングリストを縦に並べる。マトリクスは十字の軸線（横矢印・縦矢印）で4つの象限に区切られ、各象限に角丸枠のボックスが1つずつ配置される。4つのボックスのうち1つ（右上）だけが強調色の塗りつぶしで表現され、視線を最も引く要素になる。右カラムのランキングリストは見出し＋5項目で構成され、各項目はラベル（左）と数値（右）を横並びに配置し、行間を罫線で区切る。5項目のうち1項目のみ強調色文字で表現され、マトリクス側の強調ボックスと対応関係を示す。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| リード文 | コンテンツエリア上部 | スライドの主張を補足する説明文（2行程度） |
| 軸ラベル（上下左右） | マトリクス四辺 | 2軸それぞれの評価基準を示すラベル（例：「軸A（高い）」「軸B（低い）」） |

| ランキング見出し | 右カラム上部 | リストの主題を示す小見出し |
| ランキング項目（通常） | 右カラム中〜下部 | ラベルと数値のペア（4項目） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-quadrant-matrix-with-rankingのレイアウトで、[2軸の評価基準]で4分類したマトリクスと、[ランキング項目の内容]のランキングリストを配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 象限は必ずしも4つの分類対象が均等でなくてよいが、強調対象（自社等）は1象限のみに配置し、他と視覚的に区別する
- ランキングリストの項目数は4〜6件程度まで調整可能。項目数が増える場合は行の高さを詰める
- マトリクスとランキングリストで強調する対象は同一にし、両エリアで一貫した強調色を使う
