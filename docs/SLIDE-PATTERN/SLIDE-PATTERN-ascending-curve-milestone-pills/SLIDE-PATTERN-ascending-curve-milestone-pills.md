## Overview

**パターン名：** ascending-curve-milestone-pills
**概要：** 右肩上がりの塗りつぶし曲線を背景に、段階的に高さが上昇する角丸ピル型の期間ラベルを縦線でマイルストーン点に接続し、各マイルストーンに見出しと箇条書きを添えるタイムラインレイアウト。右下には大型のキャッチコピーを曲線の塗り部分に重ねて配置する。
**適したシーン：** 事業計画・成長戦略をフェーズごとの期間と達成目標とともに示し、右肩上がりの成長イメージを視覚的に印象づけたいスライド。事業計画書、成長戦略のロードマップ提示。

## Structure（構造）

コンテンツエリア上部に小見出しを配置し、その下いっぱいに右肩上がりの塗りつぶし曲線（面グラフ状の背景装飾）を敷く。曲線の上には、左から右へ進むにつれて高さが段階的に上昇する角丸ピル型の期間ラベル（例：1ヶ月後、2ヶ月後…）を配置し、ピルの直下にフェーズ見出しと2行程度の箇条書きを隙間なく続ける（ピルと見出しの間に接続線は入れない）。その本文ブロックの下端から縦線を1本伸ばし、曲線上のマイルストーン地点まで接続する。曲線が最も高くなる右下のエリアには、塗りつぶし部分に重ねる形で大型のキャッチコピー（年度・スローガン等）を白抜きで配置する。視線は左（初期フェーズ・低い位置）→右（将来フェーズ・高い位置）へ、曲線の上昇とともに流れる。

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-ascending-curve-milestone-pillsのレイアウトで、[4つのフェーズの期間・名称・達成内容]と、[年度・スローガン]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- マイルストーン数は4を基本とするが、3〜5個程度まで調整可能。ピルの高さは必ず左から右へ段階的に上昇させる
- キャッチコピーは曲線の塗りつぶし部分に重なるため、白抜き等コントラストの高い配色にする
- 既存の`arrow-timeline-four-phase`（矢印軸＋マーカー）とは異なり、本パターンは面グラフ状の曲線を背景として使い、ラベルの高さ自体で成長カーブを表現する点が特徴
- ピルとフェーズ見出しの間には接続線を引かない（隙間なく直接連続させる）。接続線は本文（箇条書き）の下端から曲線上のマイルストーン地点まで1本だけ伸ばす
- 曲線の右端の高さを画面の上端近くまで到達させると、最も高い位置にあるピル・テキストと重なる。右端の高さは上部に2割前後の余白が残る程度に抑え、各マイルストーンの接続線の終点（曲線への接続位置）もその高さに合わせて調整する
- ピルの横幅は文言の長さに対して余裕を持たせ、他パターンのバッジ・タグ類より横に広めのプロポーションにする
