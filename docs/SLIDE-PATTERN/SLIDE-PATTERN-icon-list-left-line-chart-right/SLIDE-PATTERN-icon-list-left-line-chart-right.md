このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** icon-list-left-line-chart-right
**概要：** 左カラムに4項目のアイコン付きリスト、右カラムに凡例・軸ラベル付きの折れ線グラフを配置する2カラムレイアウト。
**適したシーン：** 複数の指標・要素が時間経過とともにどう変化するかを、定性的な説明（左）と定量的な推移グラフ（右）の両面から見せたいスライド。プロセスの各フェーズの特性変化、複数KPIの時系列比較など。

## Structure（構造）

コンテンツエリア上部に主張見出し（キーメッセージ）を1行配置し、その下を左右2カラムに分割する。左カラム（約30%）は4項目の縦積みリストで、各項目は円形アイコン・見出し（アクセントカラー）・本文2行で構成され、項目間を横罫線で区切る。右カラム（約70%）は折れ線グラフで、上部に複数系列の凡例（実線・破線・点線等で系列を区別）、グラフ本体は横軸に段階ラベル（例：開始→計画→実行→監視→終了）、縦軸に高低のラベルを持つ。グラフ下部に矢印つきの補足注釈テキストを1行添える。左のリストが要素の定性的な説明、右のグラフがその推移を視覚的に示す構成で、視線は上（主張見出し）→左（要素の説明）→右（グラフでの検証）の順に流れる。

    structure:
      layout: two-column
      top_heading:
        height: 8%
        type: text
        role: コンテンツエリア冒頭のキーメッセージ（1行、太字大サイズ）
      left:
        width: 30%
        type: list
        align: 上下中央・左揃え
        role: 各要素の定性的な説明リスト
        items:
          count: 4
          count_range: 3〜5
          direction: 縦積み
          shape: 罫線区切り（枠なし）
          item_structure: 円形アイコン → 見出し（アクセントカラー） → 本文2行
      right:
        width: 70%
        type: chart
        align: 上下中央
        role: 複数系列の折れ線グラフ
        chart_structure:
          legend: 上部・系列数3程度・線種で区別（実線/破線/点線）
          x_axis: 段階ラベル（4〜6段階）
          y_axis: 高低の2値ラベル
          annotation: グラフ下部に矢印付き補足テキスト1行

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。

| 要素 | 配置 | 役割 |
|---|---|---|
| キーメッセージ | コンテンツエリア最上部 | スライド全体の主張（1行、20〜25文字程度、28px相当） |
| アイコン | 左カラム各項目上部 | 項目内容を象徴する視覚要素。生成時に内容に沿ったSVGアイコンを生成する（60px相当の円） |

| 項目本文 | 左カラム各項目 | 要素の説明（2行程度、22px相当） |

| 折れ線グラフ本体 | 右カラム中央 | 複数系列の推移を可視化するグラフ |
| 軸ラベル | グラフ四辺 | 横軸：時間・段階の推移／縦軸：高低の指標（20px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-icon-list-left-line-chart-rightのレイアウトで、[左リストに入れる4要素]の説明と、[右グラフに入れる系列・推移]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 左リストの項目数と右グラフの系列数は必ずしも一致させなくてよいが、対応関係がある場合は色を揃えると理解しやすい
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
- グラフの系列数が多い場合（4系列以上）は凡例を2行に折り返してもよい
