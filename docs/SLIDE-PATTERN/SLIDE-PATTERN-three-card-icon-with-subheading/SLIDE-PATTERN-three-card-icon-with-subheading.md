## Overview

**パターン名：** three-card-icon-with-subheading
**概要：** 上部の区切り付きリード文と、番号バナー・大アイコン・見出し・説明テキストを持つ3カードを横並びにするレイアウト（上下分割：区切りリード文＋3列カード）。
**適したシーン：** サービスの特徴説明、3つの強み・メリット提示、導入ステップ紹介、3分野のカテゴリ説明

## Usage Guide（AIへの使い方）

### 適した場面
- 3つのサービス・製品の特徴を対等に並べて紹介したい場合
- 「理由」「メリット」「ステップ」など番号付きで説明したい場合
- アイコンでカテゴリを視覚的に区別したい場合
- セクション冒頭の「何を伝えるか」を明示してからカードへ誘導したい場合

### 入れるべき情報
| エリア | 記載内容 |
|--------|--------|
| 区切りリード文 | このスライドで伝えるテーマを端的に表す短いテキスト（10〜20字程度） |
| 番号バナー | 「01」「02」「03」の連番（または「A」「B」「C」など） |
| アイコン円 | カテゴリを表すアイコン |
| カード見出し | 各カードのキーワード（10〜20字） |
| 説明テキスト | 2〜4行程度の補足説明 |

### 注意点
- 説明テキストは3カードで文字量を揃えると整って見える
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
- カードの高さは `flex: 1` により自動で揃う
- 区切りリード文が不要な場合は省略し、カードを上から配置してもよい
- デザインはSLIDE.mdに従ってください。
