# SLIDE-PATTERN-phase-banner-three-column-checklist-repeat

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** phase-banner-three-column-checklist-repeat
**概要：** リード文の下に全幅のフェーズ見出し帯を配置し、その下を縦罫線区切りの3列に分割して、各列に「番号バッジ＋見出し」「本文」「数値ハイライトボックス」「取り組みチェックリスト」を縦積みするレイアウト。
**適したシーン：** 特定フェーズ・期間内で並行して進める3つの施策・取り組みを、対象範囲の定量値と具体的なアクション項目つきで説明したいスライド。DX推進計画、施策ロードマップの各フェーズ詳細、プロジェクトの実行計画。

## Structure（構造）

コンテンツエリア上部にリード文を2行配置し、その下に全幅のフェーズ見出し帯（濃色背景・白文字・中央揃えでフェーズ名と期間を示す）を配置する。帯の下は3列均等に分割され、列と列の間は縦の罫線のみで区切り、カードのような枠・背景は使わない。各列は「丸い番号バッジ＋見出し（横並び）」から始まり、その下に本文説明（2行程度）、続いて薄い背景色のハイライトボックス（ラベルと大きな強調数値を横並びに配置）、さらに「主な取り組み」等の小見出し、最後にチェックマーク付きの箇条書き項目（3項目程度）が続く。3列は同じ内部構成を繰り返し、視線は上（フェーズ帯）→左から右へ3列を順に読む横方向の流れとなる。

    structure:
      layout: top-bottom-split
      top_lead:
        height: 10%
        type: text
        role: フェーズ全体の主旨を示すリード文（2行程度）
      phase_banner:
        height: 6%
        type: text
        role: フェーズ名・対象期間を示す全幅の帯（濃色背景・白文字・中央揃え）
      column_row:
        height: 78%
        columns: 3
        divider: 縦罫線のみ（背景・枠なし）
        item_structure: 番号バッジ＋見出し（横並び） → 本文2行 → 数値ハイライトボックス（ラベル＋強調数値） → 小見出し → チェックマーク付き箇条書き3項目

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| リード文 | コンテンツエリア最上部 | フェーズ全体の主旨を示す説明文（2行、22px相当） |
| フェーズ見出し帯 | リード文の下 | フェーズ名・対象期間を示す全幅バナー（28px相当） |
| 番号バッジ | 各列上部 | 列の順序を示す丸バッジ（24px相当） |
| 列見出し | 各列上部・番号バッジの右 | その列の施策名（26px相当） |
| 本文 | 各列上部 | 施策の概要説明（2行、20px相当） |
| 数値ハイライトボックス | 各列中央 | 対象範囲・規模を示すラベルと強調数値（ラベル20px相当・数値34px相当） |
| 小見出し | 各列下部 | 取り組み一覧の見出し（例：主な取り組み、22px相当） |
| チェックマーク付き箇条書き | 各列最下部 | 具体的なアクション項目（3項目、20px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-phase-banner-three-column-checklist-repeatのレイアウトで、[フェーズ名・期間]と、[3つの施策の見出し・対象数値・取り組み項目]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 3列は同じ内部構成を維持し、情報量（箇条書きの項目数等）を揃えるとバランスが取れる
- 数値ハイライトボックスは矢印（例：18→9）等、変化を示す表現を使ってもよい
- 既存の `phase-banner-three-column-metric-checklist` と実質的に同一の構造。同じ元スライドシリーズ（DX推進計画の異なるフェーズ）から抽出したため重複するが、指示によりあえて別名で保持している。新規デッキ作成時はどちらか一方を使えば十分
