# SLIDE-PATTERN: step-detail-photo-aside

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** step-detail-photo-aside
**概要：** 左列に縦ステップ円（課題→取り組み→成長実感等）、中列に各ステップの見出し＋箇条書き本文、右列にプロフィール写真・氏名・役職を配置した3列構成のケーススタディレイアウト。
**適したシーン：** 社員インタビュー・事例紹介・取り組み紹介で、ステップ（課題・施策・結果）と担当者情報を1枚に収めるとき。

## Structure（構造）

```yaml
structure:
  frame: standard

  left_col:
    width: 12%

  middle_col:

```

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」、アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| ステップ円 | 左列・縦配置（3個） | 各フェーズ名（課題・取り組み・成長実感等）を円で表示（24px相当） |
| 点線縦連結 | ステップ円の間 | フェーズの流れを示す縦の点線 |
| ステップ見出し | 中列・各ブロック上部 | 各フェーズのメッセージ・小見出し（太字・色付き、28px相当） |
| 箇条書き本文 | 中列・見出し下 | 具体的な施策・内容・エピソード（2〜3行、24px相当） |
| 分割線 | 中列・ブロック間 | 各ステップブロックを区切る水平線 |
| 丸型写真 | 右列上部 | 担当者・インタビュイーの顔写真（写真添付エリア） |
| 氏名 | 写真直下 | 担当者名（大きめ、36px相当） |
| 役職・所属 | 氏名下 | 英字役職名・部署名（20px相当） |

## Usage Guide（AIへの使い方）

- 左のステップ円は3個が標準。2個だと間延びする
- 中列の各ステップブロックは均等な高さにする
- 右の写真エリアは縦中央揃えにするとバランスが取れる
- ステップ円の最後（成果・成長実感）を濃い背景色にすると強調効果がある
- 中列の見出しにブランドカラーを適用すると視認性と統一感が上がる
- 写真は「写真添付エリア」としてプレースホルダーのまま生成し、ユーザーが後から実際の写真に差し替える
- デザインはSLIDE.mdに従ってください。
