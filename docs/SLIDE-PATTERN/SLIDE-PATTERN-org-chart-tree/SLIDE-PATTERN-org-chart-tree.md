# SLIDE-PATTERN-org-chart-tree

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** org-chart-tree
**概要：** 最上位ノード（役員会等）から部門、役職・業務リストへと階層的に分岐するツリー型組織図。垂直線と水平線で接続する。
**適したシーン：** 会社・部署・プロジェクトの組織体制、意思決定構造、チームの役割分担を階層的に示すとき。

## Structure（構造）

コンテンツエリアを3段のツリー構造で構成する。最上部に最上位ノードを横並びで配置し、その下に垂直線で接続する。第2層には部門ノードを横並びに配置し、それぞれ水平線で兄弟関係を示す。各部門ノードの下には垂直線で接続した役職・業務リストを縦に並べる。

    structure:
      frame: standard
      layout: tree
      levels: 3
      level_1: [board-node1, board-node2]  # 最上位（コンテンツエリア最上部）
      level_2: [dept1, dept2, dept3, dept4]  # 部門
      level_3: per-dept role-list  # 役職リスト
      connectors: vertical-horizontal-lines

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」、アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| 最上位ノード | 第1行・上部 | 取締役会・監査役会等の最高意思決定機関（26px相当） |
| 部門ノード | 第2行・中部 | CEO直下・各事業部門のノード（背景色付き、24px相当） |
| 役職・業務リスト | 第3行・下部 | 各部門に所属する役職・業務名の縦リスト（22px相当） |
| 接続線 | ノード間 | 垂直線（親子）・水平線（兄弟）で階層を表現 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-org-chart-treeのレイアウトで、〔会社・組織名〕の組織体制を最上位機関→部門→役職の3層で示してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 第2行の部門数は3〜5が適切。6以上は横幅が狭くなる
- 各部門の役職リストは4〜6項目が最適
- 最上位ノードは2つ並べる場合（取締役会＋監査役会）が多い
- 背景色付きノードはブランドカラーを使用
