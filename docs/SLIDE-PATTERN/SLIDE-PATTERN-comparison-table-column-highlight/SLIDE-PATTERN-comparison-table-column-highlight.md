# SLIDE-PATTERN-comparison-table-column-highlight

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** comparison-table-column-highlight
**概要：** 比較項目を行、自社と競合他社を列に配置した比較表で、自社列全体を枠線で強調し、各セルに補足数値（増減率等）や順位バッジを添えるレイアウト。
**適したシーン：** 自社と複数の競合他社を、複数の定量指標にわたって横断比較し、自社の優位性を視覚的に強調したいスライド。市場比較・競合分析・ポジショニング資料。

## Structure（構造）

コンテンツエリア上部にリード文を1行配置し、その下いっぱいに比較テーブルを1つ配置する単一カラムレイアウト。テーブルの列は左端に比較項目名の列、続いて自社列（1列）、その右に競合他社列（3〜4列）を横並びに配置する。自社列のみ角丸・太枠の強調線で全行を1つの囲みとして包み、ヘッダーセルの背景色を強調色にすることで視覚的に最も目立つ列として扱う。行は複数の定量指標（例：導入社数・成長率・利益率・解約率等）で構成され、各セルには主数値に加えて小さな補足情報（前年比％や王冠マーク付きの順位ラベル）を添える。表の下部または最終行には「主なターゲット」「主な強み」等の定性的な比較項目も含め、自社セルのみ複数のチェックリスト形式で強みを列挙する。テーブル全体の文字は表であっても小さくせず、比較項目名・主数値は特に大きく表示して視認性を優先する。視線は左上（比較項目ラベル）→自社列（強調）→他社列（比較対象）の順に流れる。

    structure:
      layout: single
      top_lead:
        height: 8%
        type: text
        role: 比較の主旨を示すリード文（1〜2行、24px相当）
      table:
        height: 92%
        columns: [比較項目ラベル列, 自社列（強調）, 競合列 × 3〜4]
        header_row:
          own_column: 強調色背景・角丸の太枠（枠線幅3〜4px相当・角丸12px相当）で全行を1つの囲みとして包む
          other_columns: ライトグレー背景
          font_size: 26px相当
        data_rows:
          count: 6〜9
          own_column_cell: 強調色文字・大きめフォント（主数値36〜44px相当）・補足数値（前年比等、18px相当）・順位バッジ（王冠マーク等、18px相当）
          other_column_cell: 通常フォント（28px相当）・グレー文字
        last_rows:
          type: 定性項目（ターゲット・強み等）
          own_column_cell: チェックマーク付き箇条書き（複数行、20px相当）
          other_column_cell: 1行程度の短い説明（18px相当）

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。

| 要素 | 配置 | 役割 |
|---|---|---|
| リード文 | コンテンツエリア最上部 | 比較表の主旨・結論を示す説明文（1〜2行、24px相当） |
| 比較項目ラベル列 | テーブル左端 | 各行が何を比較しているかを示す項目名（26px相当） |
| 自社列（強調） | テーブル2列目 | 角丸・太枠（角丸12px相当・線幅3〜4px相当）で全行を1つの囲みとして包み、視覚的に最も目立たせた自社の実績列。ヘッダーは強調色背景・白文字（26px相当） |
| 競合列 | テーブル3列目以降 | 比較対象となる他社の実績（3〜4社分、28px相当） |
| 主数値 | 各データ行の全列セル | 定量指標の数値本体。自社列は36〜44px相当、他社列は28px相当で自社を大きく見せる |
| 補足数値・順位バッジ | 自社列の各セル | 前年比％や「No.1」等の順位ラベルで優位性を追加訴求（18px相当） |
| 強みリスト | テーブル最終行の自社セル | 自社の強みをチェックマーク付きで複数列挙（20px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-comparison-table-column-highlightのレイアウトで、[比較する定量指標]について自社と[競合他社数]社を比較し、自社列を強調してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 既存パターンの `comparison-matrix-table`（列ハイライトで対象比較）・`comparison-table-with-highlight`（プランのセル強調）と構造が近い。本パターンは「自社1列を角丸・太枠で完全に囲み、補足数値・順位バッジを添える」点、「最終行に定性的な強みのチェックリストを持つ」点が差分となる
- 自社列を囲む強調枠は角丸であることが重要な視覚的特徴。四角い枠に置き換えない
- 競合他社の列数は3〜5社程度まで調整可能。列数が増えても表内の文字を過度に縮小しない。まず余白・行の高さを詰め、それでも収まらない場合のみフォントサイズをわずかに調整する
- 順位バッジ（王冠マーク等）は自社が実際に優位な指標のみに使用し、乱用しない
