# SLIDE-PATTERN-cover-with-image-left

このファイルはスライド全面を使うレイアウトパターン定義書です。タイトルエリア・フッターは使用しません。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** cover-with-image-left
**概要：** 左半分（約45%）に画像、右半分（約55%）にカテゴリラベル・メインタイトル・説明文・日付などのメタ情報を縦に並べる表紙レイアウト。
**適したシーン：** 提案書・レポート・プレゼンの表紙、ビジュアルを前面に出したカバースライド

## Structure（構造）

スライド全体を左右2分割で使うカバーレイアウト。左に画像、右にテキスト情報を縦に積み上げる。

    structure:
      frame: none
      layout: full-slide-two-column
      left-column:
        width: ~45%
        elements:
          - image-placeholder (full height)
      right-column:
        width: ~55%
        padding: 96px（高さの約9%）
        elements:
          - category-label (small, muted, #999)
          - main-title (large, bold, #222)
          - description (1–2 lines, #555)
          - divider-line
          - meta-info (date, author, company, #888)

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」として扱う。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| 画像プレースホルダー | 左カラム（高さ100%） | 表紙の視覚的インパクトを担う写真・イラスト領域（写真添付エリア） |
| カテゴリラベル | 右カラム上部 | 資料の種類・カテゴリを小さく表示（例：提案書・報告書、22px相当） |
| メインタイトル | カテゴリラベルの下 | プレゼンのメインタイトルを大きく太く表示（60px相当） |
| 説明文 | タイトルの下 | 1〜2行の概要説明（26px相当） |
| 区切り線 | 説明文の下 | テキストブロックとメタ情報の視覚的分離 |
| メタ情報 | 区切り線の下 | 日付・会社名・担当者などを小さく表示（24px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-cover-with-image-leftのレイアウトで、タイトル「[タイトル]」、サブタイトル「[サブタイトル]」、日付「[日付]」の表紙スライドを作成してください。左側の画像は提供した画像を使用してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- このパターンはタイトルエリア・フッターを使わず、スライド全体をコンテンツとして使う
- 左の画像はスライドの高さいっぱいに広がるようにすること。写真は「写真添付エリア」としてプレースホルダーのまま生成し、ユーザーが後から実際の写真に差し替える
- 右のテキストは上揃えより縦中央揃えの方がバランスが取りやすい
- メタ情報（日付・会社名）は省略してもよい
