# SLIDE-PATTERN-section-divider-image-right-tech

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** section-divider-image-right-tech
**概要：** 左上にロゴ、コンテンツエリア左下にセクション番号・タイトル・サブタイトルを縦に配置し、右側にテクノロジー系の抽象3Dイラスト（立方体・グリッド等）を大きく配置する章区切りレイアウト。
**適したシーン：** IT・テクノロジー企業のプレゼン資料における章・セクションの切り替え。先進性・テクノロジー感を印象づけたい章区切りページ。

## Structure（構造）

本パターンは表紙・章区切り専用のデザインとして、スライド全体（タイトルエリア・フッターエリアを含む）を使う。SLIDE.mdの通常の`Slide Frame`は表示せず、ロゴ・セクション情報・イラストのみでスライド全面を構成する。左側55〜60%を余白の多いテキストエリア、右側40〜45%をテクノロジー系3Dイラストのエリアとして分割する。左側は上部にロゴを小さく配置し、スライドの下半分・左端に「Section 数字」の英語ラベル、番号付きの和文タイトル、英語サブタイトルを縦に並べる。右側には半透明の立方体・グリッド線・光の粒子等で構成されたテクノロジー感のある3Dイラストを配置し、イラストは背景と自然に馴染むよう淡い色調で表現される。視線は左上（ロゴ）→左下（セクション情報）→右（イラストの視覚的な余韻）の順に流れる。

    structure:
      layout: two-column
      frame_note: SLIDE.mdの通常のSlide Frame（タイトル帯・ブランドフッター・ページ番号）は使わない。表紙・章区切り専用のフルスライドデザインとして扱う
      logo:
        position: 左上
        role: ブランドロゴ
      text_block:
        position: 左下寄り（コンテンツエリア下半分、左端揃え）
        width: 55〜60%
        item_structure: セクションラベル（英語、小） → 番号付き和文タイトル（大） → 英語サブタイトル（小）
      illustration:
        position: 右側
        width: 40〜45%
        role: テクノロジー系3Dイラスト（半透明立方体・グリッド線等、写真添付エリアとして扱う）

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真・イラストは「写真添付エリア（後から実際の素材に差し替え）」として扱う。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| ロゴ | 左上 | ブランドを示す小さなロゴマーク（20px相当） |
| セクションラベル | テキストブロック上部 | 章番号を示す英語ラベル（例：Section 01、16px相当） |
| セクションタイトル | セクションラベルの下 | 番号付きの章タイトル（例：01 会社概要、40px相当） |
| サブタイトル | セクションタイトルの下 | 英語の補足タイトル（18px相当） |
| テクノロジーイラスト添付エリア | 右側 | 先進性を演出する半透明3Dビジュアル。後から実際の素材に差し替える |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-section-divider-image-right-techのレイアウトで、[セクション番号・タイトル・サブタイトル]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 本パターンは表紙・章区切り専用デザインのため、SLIDE.mdの通常のタイトルエリア・フッターエリア（ブランドフッター・ページ番号）は使わない。スライド全面を使って独自にレイアウトする
- イラストは「写真添付エリア」としてプレースホルダーのまま生成し、ユーザーが後から実際の素材に差し替える
- 左側に余白の多いテキストエリア、右側にイラストのブリードエリアを配置する左右分割構図。イラストは半透明の立方体・グリッド線等でテクノロジー感を演出する
