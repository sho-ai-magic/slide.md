## Overview

**パターン名：** profile-grid-2x2-with-role-tag
**概要：** 小見出しの下に、4人分のプロフィールカード（顔写真＋役職タグ＋氏名＋経歴文）を2×2グリッドで配置するレイアウト。
**適したシーン：** 経営陣・役員紹介、チームメンバー紹介など、4人程度の人物を同等の重みで並べて詳しく紹介したいスライド。会社紹介資料、IR資料の経営陣ページ。

## Structure（構造）

コンテンツエリア上部に小見出し（例：経営層）を配置し、その下を2×2のグリッドで4人分のプロフィールカードに分割する。各カードは左側に正方形の顔写真プレースホルダー、右側に役職タグ（ピル型・枠線）と氏名（太字大）を上下に配置し、その下に経歴文（4〜5行）を続ける横並び構成。カード間は横罫線・縦罫線で区切られ、背景色の変化はない。4人は同等の重みで並び、視線は左上→右上→左下→右下の順（Z型）に流れる。

    structure:
      layout: grid
      top_heading:
        height: 8%
        type: text
        role: セクション小見出し（例：経営層）
      grid:
        height: 92%
        columns: 2
        rows: 2
        gap: 48px（幅の約2.5%）
        divider: 縦横の罫線区切り（背景色変化なし）
        item_structure: 正方形写真プレースホルダー（左） + 役職タグ・氏名・経歴文（右）の横並び

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-profile-grid-2x2-with-role-tagのレイアウトで、[4人分の役職・氏名・経歴]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 4人に満たない場合は空セルを作らず、3人の場合は1行2人＋1行1人（中央寄せ）等に調整する
- 写真は「写真添付エリア」としてプレースホルダーのまま生成し、ユーザーが後から実際の写真に差し替える
- 既存の`executive-profile-grid-2x2`と非常に近い構造。役職タグの形状（ピル型・枠線のみ）や経歴文の分量感を細部の判断基準として使い分ける
