# SLIDE-PATTERN: team-org-with-photo

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** team-org-with-photo
**概要：** 左端にリーダーの丸型写真・名前・役職を配置し、右側にグループ→ユニット→メンバーへと展開する水平ツリー型組織図を配置したレイアウト。
**適したシーン：** チームのマネージャー紹介と組織構造を同時に見せるスライド。採用資料・会社紹介・チーム体制説明。

## Structure（構造）

structure:

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」、アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| 丸型写真 | 左カラム中央 | リーダー・マネージャーの顔写真（円形クロップ、写真添付エリア） |
| 名前 | 写真直下 | リーダーの氏名（大きめ、28px相当） |
| 役職 | 名前下 | 英語役職名・部門名（20px相当） |
| 接続線 | 写真と右ツリーを繋ぐ | リーダーと配下の関係を示す水平線 |
| ユニットノード | 右側・上下2行 | チーム・ユニット名（背景色帯、24px相当）＋メンバー数（40px相当） |
| サブレベルノード | ユニットから右に延伸 | ユニットマネージャー・メンバーアイコン群（22px相当） |
| メンバーアイコン | 最右端 | 人物を表す内容に沿ったSVGアイコンで人数を表現（…で省略） |

## Usage Guide（AIへの使い方）

- 丸型写真エリアには必ず円形のクロップ枠を使う
- メンバーアイコンは「人数分並べる＋…（省略）」の表現が効果的
- ユニットが2〜3つの場合に最適。4つ以上は縦が詰まる
- 左バッジはグラデーション（上→下で色変化）にするとフローの流れが視覚化される
- ユニットノードの背景色は系統を合わせることで視認性が上がる
- 写真は「写真添付エリア」としてプレースホルダーのまま生成し、ユーザーが後から実際の写真に差し替える
- メンバーアイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
- デザインはSLIDE.mdに従ってください。
