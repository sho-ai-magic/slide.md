# SLIDE-PATTERN-center-illustration-spoke

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** center-illustration-spoke
**概要：** コンテンツエリア中央にイラスト・人物図・サービスロゴを配置し、その周囲（上・左上・左下・右上・右下）に5〜6個のアイコンを配置。各アイコンから中央へ矢印が向かうスポーク型図解。
**適したシーン：** データ収集・統合・集約の仕組み、複数チャネルから中央プラットフォームへの流入、5〜6種類の入力ソースを示すとき。

## Structure（構造）

コンテンツエリア全体を使い、中央に円形背景付きのハブ（イラスト・サービス名）を配置する。その周囲5方向（上・左上・左下・右上・右下）にアイコン付きのスポーク項目を配置し、各スポークから中央ハブへ向かう矢印（またはライン）で接続する。視線は周囲の各スポーク→中央ハブへ収束するように流れ、ハブが視覚的な求心点になる。

    structure:
      frame: standard
      layout: hub-spoke-illustration
      center:
        element: illustration-placeholder
        label: サービス名/プラットフォーム名
      spokes:
        count: 5
        positions: [top, top-left, bottom-left, top-right, bottom-right]
        elements: [icon-circle, label]
        arrows: inward（各スポークから中央ハブへ向かう線）

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」、アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| 中央イラスト | コンテンツエリア中央（半円形背景付き） | プラットフォーム・サービスを体現する写真添付エリア（サービス名28px相当・種別22px相当） |
| スポークアイコン（上） | 上部中央 | 1つ目のデータソース・入力元を示すSVGアイコン |
| スポークアイコン（左×2） | 左側上下 | 2・3番目のデータソースを示すSVGアイコン |
| スポークアイコン（右×2） | 右側上下 | 4・5番目のデータソースを示すSVGアイコン |
| 矢印/ライン | 各アイコンから中央へ | データ・情報が中央へ集まることを示す |
| ラベル | 各アイコン下 | データソース名・種別名（22px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-center-illustration-spokeのレイアウトで、中央に[サービス名/プラットフォーム名]、周囲に[データソース1〜5の名称]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 中央は人物イラストでなくサービスアイコンやロゴでも成立する
- スポーク数は4〜6が最適。7以上は配置が難しくなる
- 矢印の向きを「外向き」に変えると配布型の図解にも使える
- 中央イラストは「写真添付エリア」としてプレースホルダーのまま生成し、ユーザーが後から実際の写真・ロゴに差し替える
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
