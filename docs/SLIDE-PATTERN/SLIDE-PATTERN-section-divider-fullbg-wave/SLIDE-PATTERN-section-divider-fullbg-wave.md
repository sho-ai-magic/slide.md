# SLIDE-PATTERN-section-divider-fullbg-wave

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** section-divider-fullbg-wave
**概要：** コンテンツエリア全面を抽象的な波形グラデーション背景で覆い、左上にロゴ、左下にセクション番号・タイトル・サブタイトルを配置する章区切りレイアウト。
**適したシーン：** プレゼン資料の章・セクションの切り替え。上品で抽象的な背景を使い、落ち着いた印象で区切りたい場面。

## Structure（構造）

本パターンは表紙・章区切り専用のデザインとして、スライド全体（タイトルエリア・フッターエリアを含む）を使う。SLIDE.mdの通常の`Slide Frame`は表示せず、背景画像とロゴ・テキストのみでスライド全面を構成する。スライド全面を1枚の抽象的な波形グラデーション画像（淡い色調・光の筋のような表現）で覆い、その上にテキスト要素のみを重ねる。左上にロゴを小さく配置し、スライドの下半分・左端に「Section 数字」の英語ラベル、番号付きの和文タイトル、英語サブタイトルを縦に並べる。テキスト以外の図形要素は持たず、背景画像の質感と余白だけで章の切り替えを演出する。視線は左上（ロゴ）→左下（セクション情報）の順に流れる。

    structure:
      layout: single
      frame_note: SLIDE.mdの通常のSlide Frame（タイトル帯・ブランドフッター・ページ番号）は使わない。表紙・章区切り専用のフルスライドデザインとして扱う
      background:
        type: フルブリードの抽象波形グラデーション画像（写真添付エリアとして扱う）
        role: コンテンツエリア全体を覆う背景装飾
      logo:
        position: 左上
        role: ブランドロゴ
      text_block:
        position: 左下寄り（コンテンツエリア下半分、左端揃え）
        item_structure: セクションラベル（英語、小） → 番号付き和文タイトル（大） → 英語サブタイトル（小）

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 背景画像は「写真添付エリア（後から実際の素材に差し替え）」として扱う。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| 背景画像添付エリア | コンテンツエリア全面 | 抽象的な波形・光の筋を表現する装飾背景。後から実際の素材に差し替える |
| ロゴ | 左上 | ブランドを示す小さなロゴマーク（20px相当） |
| セクションラベル | テキストブロック上部 | 章番号を示す英語ラベル（例：Section 01、16px相当） |
| セクションタイトル | セクションラベルの下 | 番号付きの章タイトル（例：01 会社概要、40px相当） |
| サブタイトル | セクションタイトルの下 | 英語の補足タイトル（18px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-section-divider-fullbg-waveのレイアウトで、[セクション番号・タイトル・サブタイトル]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 本パターンは表紙・章区切り専用デザインのため、SLIDE.mdの通常のタイトルエリア・フッターエリア（ブランドフッター・ページ番号）は使わない。スライド全面を使って独自にレイアウトする
- 背景画像は「写真添付エリア」としてプレースホルダーのまま生成し、ユーザーが後から実際の素材に差し替える
- `section-divider-image-right-tech`と同じテキスト構図（左下寄せ）だが、本パターンは右側に独立したイラストを置かず、背景全面を1枚の画像で覆う点が差分となる
