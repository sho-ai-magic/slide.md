# SLIDE-PATTERN-donut-left-kpi-bar-right

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** donut-left-kpi-bar-right
**概要：** 左側（40%幅）に大きなドーナツグラフと中央数値を配置し、右側（60%幅）を上下に分割して上段に3つのアイコンKPI、下段に横棒グラフを並べるダッシュボード型レイアウト。
**適したシーン：** KPIダッシュボード、業績サマリー、定量レポートなど、ひとつのコンテンツエリアで複数種類の数値情報を同時に表示したいスライド。

## Structure（構造）

コンテンツエリアを左右に分割する。左（40%幅）にはドーナツグラフと中央数値・凡例を縦に中央揃えで配置する。右（60%幅）は上下に分割し、上段に3つのアイコンKPIセルを横並びで配置し、下段に複数行の横棒グラフを配置する。左右の間には区切り線を設ける。視線は左のドーナツ（総合指標）→右上のKPI（個別指標）→右下の棒グラフ（内訳）の順に流れる。

    structure:
      frame: standard
      layout: left-right-split
      left_area:
        width: 40%
        align: center
        elements:
          - area-label
          - donut-svg (width:280px / height:280px)
          - center-value
          - legend-row
      right_area:
        width: 60%
        divider: 左エリアとの間に縦の区切り線
        kpi_band:
          height: 40%程度
          layout: 3セル横並び
          border-bottom: 区切り線
          cell:
            elements: [icon-circle, value+unit, label]
        bar_area:
          height: 60%程度
          layout: 複数行の横棒グラフ（ラベル・トラック・数値の3列）

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-donut-left-kpi-bar-rightのレイアウトで、[主要達成率]をドーナツグラフに、[3つのKPI項目]をアイコン付きで、[フェーズ別の進捗内訳]を横棒グラフで配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 左のドーナツは「全体達成率」など単一の主要KPIを表示するのに最適
- 右上KPIは同じ軸（件数、金額、人数など）の異なる切り口を並べる
- 右下横棒グラフはカテゴリ別内訳や部門比較に使用する
- 凡例は2項目以内に絞り、簡潔に保つ
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
- 色はグレースケールを基本とし、実装時にSLIDE.mdのブランドカラーへ差し替える
