## Overview

**パターン名：** circle-node-step-flow
**概要：** 円形ノードを横一列に並べ、細い線で繋いだ水平フロー図。最後のノードを塗りつぶし（ゴール・完了）で強調するステッププロセス表現。
**適したシーン：** 採用フロー・申請プロセス・審査ステップなど、5〜6段階の工程を丸みのある図解で示したいとき。

## Structure（構造）

コンテンツエリア上部にフロー全体を説明するリード文を配置し、その下の中央に円形ノードを横一列に等間隔で並べ、各ノードの間を細い水平線で繋ぐ。最終ノードのみ塗りつぶしで強調し、ゴール・完了を示す。コンテンツエリア下部に補足の注記を置ける。視線は左（開始）→右（ゴール）へ流れる。

    structure:
      frame: standard
      layout: horizontal-flow
      lead_text:
        position: コンテンツエリア上部・中央揃え
        role: フロー全体の説明文（1〜2行）
      flow_row:
        position: コンテンツエリア中央
        nodes:
          count: 5
          shape: circle
          connector: thin-line
          highlight: last-node (filled)
        label_position: inside-circle
        flow_direction: left-to-right
      note_area:
        position: コンテンツエリア下部（省略可）
        role: 補足・注意事項
