# SLIDE-PATTERN-checklist-data-left-structure-right

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** checklist-data-left-structure-right
**概要：** リード文の下を左右2カラムに分割し、左に「チェックアイコン＋ラベル＋数値」の定量データリスト、右に「チェックアイコン＋見出し＋説明文」の定性的な構造リストを配置するレイアウト。
**適したシーン：** 現状の定量データ（左）と、その背景にある課題・構造の説明（右）を対応づけて見せたいスライド。現状分析、課題提起、導入前の状況説明。

## Structure（構造）

コンテンツエリア上部にリード文を2〜3行配置し、その下を左右2カラムに均等分割する。左カラムは小見出し（例：データ一覧を示す小見出し）の下に、チェックボックスアイコン・ラベル・数値を横並びにした項目を縦に4項目並べ、項目間を罫線で区切る。右カラムは小見出し（例：課題一覧を示す小見出し）の下に、チェックボックスアイコン・太字見出し・説明文を横並びにした項目を縦に4項目並べ、同じく項目間を罫線で区切る。左カラムは数値が右揃えで大きく強調され、右カラムは見出しが太字で強調される。左右の項目数は対応しており、左の数値がもたらす課題を右で説明する構成。視線は上（リード文）→左（定量データ）→右（構造説明）の順に流れる。

    structure:
      layout: two-column
      top_lead:
        height: 12%
        type: text
        role: 現状説明のリード文（2〜3行）
      left:
        width: 48%
        type: list
        role: 定量データのチェックリスト
        sub_heading: 左カラム上部の小見出し
        items:
          count: 4
          direction: 縦積み・罫線区切り
          item_structure: チェックボックスアイコン → ラベル（左） → 数値（右、大きく強調）
      right:
        width: 48%
        type: list
        role: 定性的な課題構造のチェックリスト
        sub_heading: 右カラム上部の小見出し
        items:
          count: 4
          direction: 縦積み・罫線区切り
          item_structure: チェックボックスアイコン → 太字見出し → 説明文（1行）
      gap: 64px

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-checklist-data-left-structure-rightのレイアウトで、[左に入れる定量データ4項目]と、[右に入れる課題構造4項目]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 左右の項目数は必ず一致させ、同じ行に対応関係のある内容を配置すると理解しやすい
- 左カラムの数値は単位（%・時間等）を数値の後ろに小さく添えてもよい
- 既存の `two-col-icon-list-comparison`（カラーアイコン＋テキストの2カラム比較）と近い構造だが、本パターンは左カラムが「ラベル＋数値」のペア形式である点が差分となる
