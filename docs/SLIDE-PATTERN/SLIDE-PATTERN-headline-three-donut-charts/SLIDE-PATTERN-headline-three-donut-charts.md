## Overview

**パターン名：** headline-three-donut-charts
**概要：** コンテンツエリア上部に大きな見出し2行（キーメッセージ）を配置し、下部に3つのドーナツグラフを横並びで表示する数値インパクトレイアウト。重要なメッセージを文字で強調しながら、その根拠となる3つの数値指標をグラフで視覚化したい場合に適している（情報密度：中／メッセージ＋グラフ3点の明快な構成、方向性：「言葉のインパクト＋数値の裏付け」の組み合わせ）。
**適したシーン：** エグゼクティブサマリー、成果発表、数値インパクト訴求

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-headline-three-donut-chartsのレイアウトで、〔伝えたい成果・キーメッセージ〕を2行の大見出しに配置し、下部に〔3つの数値指標〕をドーナツグラフで表現してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 見出しは「〇〇が△△%改善」「□□において◇◇を達成」のように、具体的な成果を短く記述する
- 3つのドーナツは同じ指標種別（達成率、割合、スコアなど）で統一するとわかりやすい
- 見出し文字サイズは40px相当を基準とし、文字数が多い場合は36px相当まで縮小可
- 説明テキストは1行に収める。2行になる場合はfont-size:20px相当へ調整する
- 凡例はデータ名と残り（「その他」等）の2項目で構成する
