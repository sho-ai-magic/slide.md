# SLIDE-PATTERN-gradient-fullbleed-title-divider

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** gradient-fullbleed-title-divider
**概要：** スライド全面をグラデーション背景で覆い、左上にロゴ、左下に大型のセクションタイトルのみを配置するミニマルな区切りページレイアウト。
**適したシーン：** 事業セクションの区切り、章の切り替えページなど、装飾的な背景で視覚的な転換を印象づけたいスライド。プレゼン中盤の事業紹介パートの導入。

## Structure（構造）

本パターンは表紙・章区切り専用のデザインとして、スライド全体（タイトルエリア・フッターエリアを含む）を使う。SLIDE.mdの通常の`Slide Frame`は表示せず、背景・ロゴ・タイトルのみでスライド全面を構成する。スライド全面をグラデーション背景（多色の抽象的なグラデーション、フルブリード）で覆い、他の要素は最小限に絞る。左上にロゴを小さく配置し、左下寄りに大型のタイトルテキストのみを白抜きで1行配置する。本文・箇条書き・図解などの補足要素は一切持たず、背景の色彩とタイトルの対比だけで視覚的なインパクトを作る。視線は自然とタイトルテキストに集中する。

    structure:
      layout: single
      frame_note: SLIDE.mdの通常のSlide Frame（タイトル帯・ブランドフッター・ページ番号）は使わない。表紙・章区切り専用のフルスライドデザインとして扱う
      background:
        type: フルブリードのグラデーション背景（複数色・有機的な形状）
        role: スライド全体の視覚的な転換・印象づけ
      logo:
        position: 左上
        role: ブランドロゴ（小さく配置）
      title:
        position: 左下寄り
        type: text
        role: セクション名を示す大型タイトル（1行、白抜き）

| 要素 | 配置 | 役割 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-gradient-fullbleed-title-dividerのレイアウトで、[セクションタイトル]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 本パターンは表紙・章区切り専用デザインのため、SLIDE.mdの通常のタイトルエリア・フッターエリア（ブランドフッター・ページ番号）は使わない。スライド全面を使って独自にレイアウトする
- 要素を極力削ぎ落とし、背景とタイトルのみのミニマルな構成を維持する。補足文や箇条書きを追加しない
- グラデーションの配色はSLIDE.mdのブランドカラーに合わせて調整する
- 既存の`cover-gradient-text-bottom`（表紙ページ用のグラデーション＋下部テキスト）と近い構造だが、本パターンは表紙ではなく章区切り用として使う点が異なる
