# SLIDE-PATTERN-four-step-flow

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** four-step-flow
**概要：** コンテンツエリアいっぱいに4枚の等幅カードを横並びにしたフロー図レイアウト。各カードは番号バッジ・ラベル・イラストで構成され、カード間の矢印でステップの流れを示す。
**適したシーン：** プロセス・手順・ワークフローの説明。「〜の進め方」「〜のステップ」のように順序のある内容を視覚的に整理したいときに最適。

## Structure（構造）

コンテンツエリア全体に4つの等幅カードを横に並べる。カード間には順序を示す矢印（▶）を挟む。各カードは上部に番号バッジ（丸形・アクセントカラー）、中央上にテキストラベル、中央下にイラストを縦に積み上げる構成。

    structure:
      frame: standard
      layout: four-column-flow
      columns: 4
      cards:
        count: 4
        width: 約22%（カード間の矢印スペースを除いた等分）
        separator: arrow（▶、カード間に配置）
        card_elements:
          - badge: 番号（1〜4）、円形、上部中央に重ね表示
          - label: ステップ名テキスト、カード上部
          - illustration: イラスト・アイコン、カード下部

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」、アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| カード（×4） | 横並び・等幅 | 各ステップのコンテナ。角丸・ボーダー付き |
| 番号バッジ | 各カードの上端中央（カードに重ねて表示） | ステップの順序を示す番号（1〜4）（32px相当） |
| ステップラベル | 各カード中央上部 | そのステップで行うことの短い説明（1〜2行）（30px相当） |
| イラスト | 各カード中央下部 | ステップの内容を補強するビジュアル（内容に沿ったSVGアイコンを生成して配置） |
| 矢印（▶） | カード間（計3箇所） | ステップの進行方向・順序の明示 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-four-step-flowのレイアウトで、4つのステップは①[ステップ1]、②[ステップ2]、③[ステップ3]、④[ステップ4]です。デザインはSLIDE.mdに従ってください。」

**注意点：**
- ステップ数は4固定のパターン。3ステップや5ステップに変える場合はカード数を調整すること。
- イラストは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する。
- 番号バッジの色はデザインシステムのアクセントカラーを使用する。
- ステップラベルは1〜2行に収まる短い文言が望ましい（長文は視認性を損なう）。
