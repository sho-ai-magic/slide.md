## Overview

**パターン名：** three-stage-process-with-annotations
**概要：** 3段の横長カラーブロック（各段に色帯ラベル＋複数アイコン項目を横並び）を縦に積み、右側に各段対応の注釈テキストと最終成果物ボックスを配置する処理フロー図解レイアウト。
**適したシーン：** インプット→処理→アウトプットのような3段階の処理フローを、各段の詳細項目と、なぜその設計が重要かという補足説明（右側の注釈）を対応づけて示したいスライド。業務プロセス・データ処理フロー・意思決定フローの解説。

## Structure（構造）

コンテンツエリアは左右に分割され、左側（約75%）に3段の横長カラーブロックを縦に積み重ね、右側（約25%）に各段に対応する注釈テキストと最終成果物を配置する。左側の各段は異なるアクセントカラーの帯ラベル（「インプット」「処理」「アウトプット」等の段階名）を左端に持ち、その右に2〜4個のアイコン項目を横並びで配置する。各アイコン項目はアイコン・見出し・補足説明の縦積み構成。段と段の間は下向き矢印で接続される。右側の注釈エリアは各段の高さに合わせて配置され、「なぜこの設計が重要か」を示す短いフレーズを矢印付きで左（各段）に向けて示す。最下段の右端には最終成果物を表すハイライトボックス（アイコン＋名称＋効果の一言）を配置し、全ての段からの矢印がここに集約される。コンテンツエリア最下部には全体のまとめを1行で示す帯を配置する。

    structure:
      layout: two-column
      left:
        width: 75%
        type: process-stages
        align: 上下均等
        role: 3段階の処理フロー詳細
        stages:
          count: 3
          direction: 縦積み
          connector: 下向き矢印
          stage_structure: 色帯ラベル（段階名） → アイコン項目の横並び（2〜4個）
          item_structure: アイコン → 見出し → 補足説明
      right:
        width: 25%
        type: annotation
        align: 各段の高さに合わせて配置
        role: 各段の設計意図を示す注釈テキスト（矢印付き）＋最終成果物ボックス
      bottom_summary:
        height: 8%
        type: text
        role: 全体のまとめを示す帯（アイコン＋1行メッセージ）

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。

| 要素 | 配置 | 役割 |
|---|---|---|
| 段階ラベル帯 | 各段左端 | 段階名を示す色分けされたラベル（例：インプット／処理／アウトプット、22px相当） |
| アイコン項目 | 各段のラベル右側 | その段階を構成する要素（アイコン48px相当＋見出し20px相当＋補足説明16px相当）。段あたり2〜4個 |
| 段間矢印 | 各段の間 | 処理の流れる方向を示す |
| 注釈テキスト | 右カラム、各段に対応する高さ | その段の設計が重要な理由を示す短いフレーズ（18px相当） |
| 最終成果物ボックス | 右カラム下部 | 3段のフローが最終的に生み出す成果物を示す強調ボックス |
| まとめ帯 | コンテンツエリア最下部 | 3段階全体の要旨を1行でまとめる（20px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-three-stage-process-with-annotationsのレイアウトで、[3段階の処理内容]と、[各段の設計意図]、[最終成果物]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 各段のアイコン項目数は2〜4個の範囲で調整可能。段ごとに項目数が異なってもよい
- 3段の色帯は段階が進むにつれて色相・濃淡を変えると流れが視覚的に伝わりやすい
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
