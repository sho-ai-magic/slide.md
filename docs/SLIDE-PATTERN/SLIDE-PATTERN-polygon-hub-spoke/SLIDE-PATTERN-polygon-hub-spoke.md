# SLIDE-PATTERN-polygon-hub-spoke

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** polygon-hub-spoke
**概要：** コンテンツエリア中央に多角形（ペンタゴン/ヘキサゴン等）を配置し、各頂点に番号付き円バッジを置く。各頂点の外側（上・左・右）に説明テキストパネルを放射状に配置するハブ＆スポーク型レイアウト。
**適したシーン：** 相互に連関する5〜6つの要素・メリット・課題を等価に並べて中心テーマとの結びつきを示したいとき。

## Structure（構造）

コンテンツエリアの中央に多角形ダイアグラムを配置し、多角形の各頂点に沿って番号バッジを並べる。各バッジから放射方向に点線を伸ばし、その先に説明テキストブロック（見出し＋本文）を接続する。上部に1ブロック、右側2ブロック・左側2ブロックに振り分ける構成が基本形。左側のテキストブロックは右揃え、右側のテキストブロックは左揃えにして、多角形側に文字が寄るようにする。

    structure:
      frame: standard
      layout: radial-polygon
      center:
        element: polygon-shape
        sides: 5
        label: center-theme
      spokes:
        count: 5
        node: circle-badge
        content: heading + body-text
        distribution:
          top: 1
          right: 2
          left: 2

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」、アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| 多角形（ペンタゴン） | 中央 | 全体テーマを内包する図形。頂点が各スポークのアンカーになる |
| 中央ラベル | 多角形の内部 | テーマ名（26px相当）・コンセプト名（20px相当）を表示 |
| 番号バッジ（円） | 各頂点 | 連番（01〜N）を入れた小円（22px相当）。頂点と説明テキストをつなぐ中継点 |
| 見出し | 各バッジの外側 | 各スポークのトピック名（22px相当） |
| 本文テキスト | 見出しの下 | 各スポークの説明・根拠・補足（20px相当・2〜4行程度） |
| 多角形の頂点をつなぐ点線 | 頂点とテキストブロックの間 | 要素間の相互連関を示す接続線 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-polygon-hub-spokeのレイアウトで、[中心テーマ]の[メリット/要素/課題]を5項目放射状に配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 多角形の辺数（頂点数）は項目数に合わせる（5項目→ペンタゴン、6項目→ヘキサゴン）
- 各説明テキストブロックは左側グループ・右側グループでテキスト揃え方向を変える（左グループは右揃え、右グループは左揃えが読みやすい）
- 多角形は塗りつぶし色を薄くし、テキストの可読性を確保する
- 本文テキストが長い場合は行間を広めにとり、バッジとの間隔を一定に保つ
- アイコンを使う場合は、元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
