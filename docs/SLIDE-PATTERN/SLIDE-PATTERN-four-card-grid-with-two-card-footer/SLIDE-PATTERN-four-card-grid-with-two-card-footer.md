## Overview

**パターン名：** four-card-grid-with-two-card-footer
**概要：** 上段に4列均等のカードグリッド（アイコン・見出し・本文・補足図解を内包）、下段に2列均等のカードグリッドを配置する2段構成の情報過多型レイアウト。
**適したシーン：** 4つの分類・パターンを主説明としつつ、それに付随する補足トピック（例外ケース・使い分けのポイント等）を2つ添えたいスライド。フレームワークの全体像と補足情報を1枚で網羅的に見せたい場面。

## Structure（構造）

コンテンツエリア上部に主張見出しを1行配置し、下部を上下2段のカードグリッドで構成する。上段は4列均等のカードを横並びに配置し、各カードはアイコン・見出し・本文2行に加えて、内部にミニ図解（ドット付きタイムラインやステップ列等、カードの内容に応じた小さな図）と、具体例を示す小さなラベルボックスを持つ。下段は2列均等のカードを横並びに配置し、各カードはアイコン・見出し・本文2行に加えて、内容に応じた補助図解（アイコン列やフロー図等）を持つ。上段4カードが主要な分類の並列提示、下段2カードが補足・派生トピックという役割分担で、視線は上段（横4分割）→下段（横2分割）の順に流れる。

    structure:
      layout: top-bottom-split
      top_heading:
        height: 8%
        type: text
        role: コンテンツエリア冒頭のキーメッセージ（1行）
      top_grid:
        height: 55%
        columns: 4
        gap: 32px
        item_structure: アイコン → 見出し → 本文2行 → ミニ図解 → 具体例ラベルボックス
        shape: 枠線カード・上下区切り線あり
      bottom_grid:
        height: 37%
        columns: 2
        gap: 32px
        item_structure: アイコン → 見出し → 本文2行 → 補助図解
        shape: 枠線カード

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。

| 要素 | 配置 | 役割 |
|---|---|---|
| キーメッセージ | コンテンツエリア最上部 | スライド全体の主張（1行、20〜25文字程度、26px相当） |
| 上段カードアイコン | 各上段カード上部 | カードの分類を象徴する視覚要素。生成時に内容に沿ったSVGアイコンを生成する（48px相当の円） |
| 上段カード見出し・本文 | 各上段カード中央 | 分類名（6〜10文字、24px相当）と説明文（1〜2行、19px相当） |
| ミニ図解 | 各上段カード下部 | 分類の性質を示す簡易図（例：単発／複数回／周期的／継続的の違いを表す点列） |
| 具体例ラベルボックス | 各上段カード最下部 | 分類の具体例を1件示す小さなラベル（16px相当） |
| 下段カードアイコン・見出し・本文 | 各下段カード上部〜中央 | 補足トピックの名称とアイコン（24px相当）、説明文（1〜2行、19px相当） |
| 補助図解 | 各下段カード右側 | 補足トピックの内容を視覚的に示す簡易図（アイコン列・フロー等） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-four-card-grid-with-two-card-footerのレイアウトで、[上段4カードに入れる分類]と、[下段2カードに入れる補足トピック]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 情報量が多いパターンのため、本文は簡潔に保ち、図解要素で視覚的に補う
- 上段カードのミニ図解は分類ごとに異なる表現（点の疎密・矢印の連続性等）にすると違いが伝わりやすい
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
