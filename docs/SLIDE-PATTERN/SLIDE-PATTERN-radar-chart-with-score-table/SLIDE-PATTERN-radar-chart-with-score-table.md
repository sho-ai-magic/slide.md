# SLIDE-PATTERN-radar-chart-with-score-table

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** radar-chart-with-score-table
**概要：** リード文の下を左右2カラムに分割し、左に総合スコアボックス＋レーダーチャート（5軸）、右に評価項目別のスコア表（項目名・説明・点数）を配置するレイアウト。
**適したシーン：** 複数の評価軸で自社・現状を診断し、総合スコアと各軸の詳細スコアを同時に見せたいスライド。成熟度診断、レベル診断、多角的な自己評価の提示。

## Structure（構造）

コンテンツエリア上部にリード文を2〜3行配置し、その下を左右2カラムに分割する。左カラム（約38%）は上部に総合スコアを示す枠付きボックス（見出し帯＋大きな分数表記「◯◯/100」）を配置し、その下に5軸のレーダーチャート（五角形の同心グリッド、各軸に軸ラベルと数値を表示、データ領域を塗りつぶしと太い輪郭線で強調）を配置する。右カラム（約58%）には評価項目別のスコア表を配置し、ヘッダー行（評価項目／スコア）の下に、項目ごとに「項目名（強調色・太字）＋説明文（小さめ）」のセルと「点数（大きく強調）」のセルを横並びにした行を5行縦に並べる。行間は横罫線で区切る。視線は左（総合スコア→軸ごとの傾向）→右（各項目の詳細説明・点数）の順に流れる。

    structure:
      layout: two-column
      top_lead:
        height: 12%
        type: text
        role: 診断の背景・要点を示すリード文（2〜3行）
      left:
        width: 38%
        type: score-summary
        role: 総合スコアとレーダーチャート
        score_box:
          shape: 角丸の枠付きボックス、上部に見出し帯（背景色塗り）
          content: 大きな分数表記（例：62/100）
        radar_chart:
          axes: 5
          shape: 五角形の同心グリッド（複数段階の目盛線）
          data_area: 塗りつぶし＋太い輪郭線で強調
          axis_label: 各軸の名称と数値を軸の外側に表示
      right:
        width: 58%
        type: score-table
        role: 評価項目別の詳細スコア表
        header_row:
          background: 濃色背景・白文字
        rows:
          count: 5
          item_structure: 項目名（強調色・太字）＋説明文（左寄せ） → 点数（大きく強調、右寄せ）
          divider: 横罫線区切り

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| リード文 | コンテンツエリア最上部 | 診断の背景・結論を示す説明文（2〜3行、22px相当） |
| 総合スコアボックス見出し | 左カラム上部 | ボックスの主題（例：総合成熟度（100点満点）、20px相当） |
| 総合スコア数値 | 見出しの下 | 100点満点中の総合点（大きく強調、56px相当）＋分母（24px相当） |
| レーダーチャート | 左カラム下部 | 5軸の評価バランスを視覚化する図形 |
| 軸ラベル・軸数値 | レーダーチャート各頂点 | 各評価軸の名称とスコア（軸名18px相当・数値28px相当） |
| スコア表見出し帯 | 右カラム最上部 | 表全体の主題（例：評価項目別スコア、22px相当） |
| 項目名 | 各行左側 | 評価項目の名称（強調色、22px相当） |
| 項目説明文 | 項目名の下 | その項目が評価する内容の説明（17px相当） |
| 点数 | 各行右側 | その項目のスコア（大きく強調、32px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-radar-chart-with-score-tableのレイアウトで、[5つの評価項目]とその[スコア・説明]、[総合スコア]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 評価軸は5軸を基本とするが、4〜6軸程度まで調整可能。軸数が変わってもレーダーチャートの正多角形の形は崩さない
- レーダーチャートのデータ領域の塗り色と、右表の点数の強調色は同系色に揃えて対応関係を示すとよい
- 項目数が5を超える場合は表の行の余白を詰めて対応し、フォントサイズは最低目安を下回らせない
