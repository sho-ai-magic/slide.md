# SLIDE-PATTERN-section-divider

このファイルはスライド全面を使うレイアウトパターン定義書です。タイトルエリア・フッターは使用しません。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** section-divider
**概要：** チャプター区切りスライド。左端に太い縦線、その右に大きなセクション番号・セクションタイトル・サブタイトルを縦に並べ、余白を活かしたシンプルな構成。
**適したシーン：** プレゼンの章区切り、セクション導入、アジェンダ後の各パートの冒頭スライド

## Structure（構造）

スライド全面（1920×1080px）を縦方向中央揃えで使用する。左端に太い縦線アクセントを置き、その右にセクション番号・タイトル・サブタイトルを縦に並べる。下部にオプションでページ範囲テキストを配置できる。

    structure:
      frame: none
      layout: full-slide-centered-vertical
      left-accent:
        type: vertical-line (8px 相当・1920px基準)
      main-content:
        alignment: vertical-center
        elements:
          - section-number (large, muted, #AAAAAA)
          - section-title (large, bold, #333)
          - sub-title (small, #666)
      footer-optional:
        - page-range-text (small, #AAAAAA)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 縦線アクセント | スライド左側 | セクションの存在感を演出するビジュアルアクセント |
| セクション番号 | 縦線の右・上部 | 「01」「02」など章番号を大きく表示し、構成を明示（96px相当） |
| セクションタイトル | 番号の下 | 章の主題タイトルを大きく太く表示（64px相当） |
| サブタイトル | タイトルの下 | 章の内容を一言で補足する説明文（30px相当） |
| ページ範囲（任意） | スライド右下 | この章で扱うページ範囲（例: P.10–15）を小さく表示（22px相当） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-section-dividerのレイアウトで、セクション番号「02」、セクションタイトル「[タイトル]」、サブタイトル「[サブタイトル]」の区切りスライドを作成してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- タイトルエリア・フッターは使用せず、スライド全面をシンプルに使うこと
- セクション番号は「01」「02」のようなゼロパディング2桁が定番
- 余白を多めに取りシンプルに仕上げることで、前後スライドとのコントラストが生まれる
- ページ範囲テキストは省略しても構わない
