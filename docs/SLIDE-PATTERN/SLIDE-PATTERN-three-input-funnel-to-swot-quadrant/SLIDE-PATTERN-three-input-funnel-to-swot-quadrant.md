## Overview

**パターン名：** three-input-funnel-to-swot-quadrant
**概要：** 左に3つの入力ボックス（アイコン＋ラベル＋説明を縦積み）を矢印で右の2×2マトリクス（4象限、各アイコン＋ラベル＋箇条書き）に接続し、その下に統合ボックス、最下部に全体のまとめ帯を配置する複合図解レイアウト。
**適したシーン：** 複数の分析フレームワークの結果を1つのマトリクスに統合し、そこから導かれる結論を示したいスライド。戦略分析（PESTLE・Five Forces・3C→SWOT等）、複数インプットから1つの意思決定への統合プロセスの説明。

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-three-input-funnel-to-swot-quadrantのレイアウトで、[3つの分析フレームワーク]の結果を、[4象限マトリクスの各項目]に整理し、[統合結果・まとめ]を配置してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 4象限は本来SWOT（強み・弱み・機会・脅威）を想定しているが、他の4分類フレームワークにも応用できる
- 情報量が多いパターンのため、各象限の箇条書きは4項目程度に絞り、文字が小さくなりすぎないようにする
- アイコンは元スライドの見た目を再現せず、スライドの内容に沿ったSVGアイコンを生成して配置する
- 3つの入力ボックスは、それぞれ個別の接続コネクターでマトリクスに接続する。入力ボックス同士を縦矢印でつなぐ表現や、中央に1本だけ矢印を置く簡略化は、3入力→1マトリクスという構造が伝わらないため避ける
- 各象限のアイコンと統合ボックスのラベルバッジは省略されがちな要素だが、Elements表に定義されている場合は必ずHTMLに反映する。生成後、Structure/Elementsに書いた要素がHTML上で欠落していないか突き合わせて確認する
- 入力列とマトリクス列の間隔は、gap（余白の値）ではなく間に置く「接続コネクター用カラム」の幅で表現する。gapを極端に広げて間隔を作ると、コネクター（矢印）だけが浮いて見え、入力とマトリクスの接続関係が伝わりにくくなる
- コンテンツの合計幅がコンテンツエリアの横幅ぴったりになるよう、各カラムの幅（%とpxの混在）とgapの合計を事前に計算し、右側に余分な空白ができたり逆にはみ出したりしないようにする
