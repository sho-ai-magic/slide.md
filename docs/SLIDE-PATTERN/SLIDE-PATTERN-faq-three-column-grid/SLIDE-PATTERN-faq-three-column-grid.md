# SLIDE-PATTERN-faq-three-column-grid

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・フッター（ブランドフッター・ページ番号）・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** faq-three-column-grid
**概要：** FAQ（よくある質問と回答）を3列×2行のグリッドに整列して配置するレイアウト。各セルは「Q番号バッジ」「質問テキスト（太字）」「回答テキスト」で構成される。
**適したシーン：** よくある質問と回答・導入事例Q&A・製品FAQ・懸念事項への回答スライドなど、複数の質問と答えをコンパクトにまとめたいシーン

## Structure（構造）

コンテンツエリアは3列×2行の均等グリッドで構成される。各セルはボーダー付きカードで、上部中央に「Q番号バッジ（着色背景の小ボックス）」、その下に質問テキスト（太字・やや大きめ）、さらに下に回答テキスト（通常ウェイト・小さめ）が縦に並ぶ。グリッドは左上から右へ、上段→下段の順に並ぶ。

    structure:
      frame: standard
      layout: grid
      columns: 3
      rows: 2
      gap: 24px（コンテンツエリア幅の約1.5%）
      cell:
        elements: [q-badge, question-text, answer-text]
        border: true
        badge-position: top-center

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真は「写真添付エリア（後から実際の写真に差し替え）」、アイコンは「内容に沿ったSVGアイコンを生成して配置」として役割を記述する。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| Qバッジ | 各セル・上部中央 | 質問番号を着色背景の小ボックスで表示（例：Q1、Q2）（24px相当） |
| 質問テキスト | 各セル・バッジの下 | 質問内容を太字・やや大きめのフォントで表示（24px相当） |
| 回答テキスト | 各セル・質問の下 | 回答内容を通常ウェイト・小さめのフォントで表示（22px相当） |
| セルボーダー | 各セル外周 | カード状の枠線で各Q&Aを視覚的に区切る |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-faq-three-column-gridのレイアウトで、サービス導入に関するよくある質問を6件まとめてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- Q番号バッジはSLIDE.mdのアクセントカラーで着色する
- セル数は6個（3列×2行）が最適。4〜5個の場合は空きセルにスペーサーを使用する
- 質問テキストは2〜3行、回答テキストは3〜5行に収まるよう内容を調整する
- セル同士の余白（gap）は均等に取り、全体が詰まって見えないようにする
