# SLIDE-PATTERN: cover-logo-mark-centered

このファイルはスライド全面を使うレイアウトパターン定義書です。タイトルエリア・フッターは使用しません。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。文言はすべてサンプル（ダミーテキスト）です。

## Overview

**パターン名：** cover-logo-mark-centered
**概要：** ロゴマーク（シンボル）を上部に置き、その直下にタイトル・会社名・日付・付加情報を縦に積み上げた中央揃えの表紙レイアウト。
**適したシーン：** 決算説明会、IR資料、企業紹介プレゼン、金融機関向け資料、上場企業の公式発表

## Structure（構造）

```
structure:
  frame: none
  layout: single-column
  alignment: center
  elements:
    logo_mark: top-center (large symbol)
    main_title: below-logo (large, bold)
    company_name: below-title
    date: below-company
    additional_info: below-date (stock code etc.)
```

## Elements（各要素の役割）

※ タイトル（H1）・フッターはSLIDE.mdの Slide Frame で定義されるため、この表には含めない。コンテンツエリアの要素のみを記述する。
※ 写真・ロゴは「写真添付エリア（後から実際の写真に差し替え）」として扱う。
※ 文字要素には、元スライドの見た目から見積もった1920px基準のフォントサイズの目安を役割欄に添える。

| 要素 | 配置 | 役割 |
|---|---|---|
| ロゴマーク | 中央上部 | シンボルロゴ（円形・モノグラム等、写真添付エリア） |
| メインタイトル | マーク直下 | 資料の主タイトル（大きなフォント、60px相当） |
| 会社名 | タイトル下 | 正式会社名（中フォント・太字、32px相当） |
| 日付 | 会社名下 | 作成・発表年月（26px相当） |
| 付加情報 | 最下部 | 証券コード・市場区分等（24px相当） |

## Usage Guide（AIへの使い方）

- ロゴマーク（シンボル）がないブランドの場合はロゴ横長タイプに差し替え可能。ロゴは「写真添付エリア」としてプレースホルダーのまま生成し、ユーザーが後から実際のロゴに差し替える
- タイトルと会社名の間の仕切り線はブランドカラーを適用
- 5〜6要素の縦積みが標準。それ以上増やすと間隔が詰まる
- ロゴマークのサイズはスライド高さの13〜15%程度を目安にする
- 仕切り線の幅は80〜120px程度。ブランドカラーのアクセントラインとして機能する
- 付加情報（証券コード等）はオプション。不要な場合は省略可能
